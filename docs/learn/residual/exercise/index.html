推导与分析

先写出推导、计算或反例，再展开参考解核对假设与关键步骤。编程题位于下方，可从本页目录直接进入。

从 y=x+F(x) 推导输入梯度，为什么残差有助于传播，却不保证梯度永远不为零？

参考解与分析

对输入求导得到 I+JFI+J_FI+JF​⁠，直接路径贡献恒等矩阵，分支贡献自己的 Jacobian。这让梯度不必完全依赖穿过分支的所有连续乘法。

恒等项与分支项仍可能抵消，多层乘积也可能放大或缩小。标量例子 F(x)=0.5x2F(x)=0.5x^2F(x)=0.5x2 在 x=−1x=-1x=−1 处，导数 1+x 恰好为零，因此不能把残差解释为绝对的稳定性保证。

代码对应：对照 residual_value_grad，并检查实际模块输入和分支输出的梯度范数。

  • 给出 I+JFI+J_FI+JF​ 或标量 1+F′(x)1+F'(x)1+F′(x)⁠。
  • 能举出抵消情形或说明多层尺度仍需监测。

新增残差分支的最后一层初始化为零，为什么首步更早层梯度可能为零，而最后一层仍能学习？

参考解与分析

最后一层为零时，整个分支输出为零，残差块可以保持初始主路径。反向传播到更早层时会乘以这个零权重矩阵，因此早层梯度可能为零。

最后一层自身的梯度依赖它的输入激活与上游梯度，不必乘自己的权重，所以仍可能非零。完成一次更新后，分支内部的梯度路径可能打开；应检查分层梯度和后续更新，而不是只看首步零梯度。

代码对应：对照 pre.ffn[-1].weight.grad 与 pre.ffn[0].weight.grad，再执行一次实际更新后复查。

  • 解释零末层为何保留初始残差行为。
  • 区分末层参数梯度与传向更早层的梯度。

两层分支范数都很小，或所有残差 Jacobian 的特征值都接近 1，是否足以保证深层梯度稳定？

参考解与分析

不足。分支输出值小不代表其局部导数小，例如高频的小幅函数可以有很大导数。梯度由各层 Jacobian 的乘积决定。

取每层 A=[1k01]A=\begin{bmatrix}1&k\\0&1\end{bmatrix}A=[10​k1​]⁠，特征值均为 1，但 Aᴸ 的右上角为 Lk。方向间的耦合会累积，不能仅凭特征值判断放大。

残差范数、分支范数和逐层梯度都是有用观测量，但不能互相代替；Pre-Norm 的恒等项也不是所有方向上的梯度下界。

代码对应：使用 matrix_power 验证 Aᴸ，再比较 Aᴸ 对不同单位向量的放大。

  • 区分函数值与导数。
  • 解释特征值为 1 的矩阵仍可因方向耦合而累积放大。

为什么比较不同模型的 loss.backward() 输入梯度，不能单独证明谁的 Jacobian 传播更稳定？

参考解与分析

任务梯度是 J⊤gJ^\top gJ⊤g⁠，其中 g 还依赖模型当前输出与损失。两个模型的初始预测不同，g 的方向和尺度也可能不同。观测到输入梯度差异时，无法仅凭该值区分来自 J 还是来自上游误差。

本节先固定同一个单位输出方向求 VJP，再单独训练和报告 MSE。即使这样，单个探针也不是对所有奇异方向的证明；它提供受控且可复现的局部证据。

代码对应：完整实现的 probe 与 train 分别记录传播和任务优化。

  • 写出 J⊤gJ^\top gJ⊤g 并区分两个因子。
  • 说明共享初值、同一数据、固定 α\alphaα 与单方向探针的边界。

残差提供恒等梯度项，但不保证总梯度处处非零。

辨析与纠错

判断下面的说法或实现会在哪一步失效，并说明成立所需的条件，再展开分析核对。

把残差当作梯度永不消失的保证

F(x)=−xF(x)=-xF(x)=−x 就能抵消恒等项。记录各层梯度和分支/主流尺度，用实际结构解释异常。

Post-Norm 零分支也要求输出等于 x

外层 Norm 仍然生效。按 y=Norm(x) 构造预期，不要把 Pre-Norm 的测试直接搬过来。

为省显存 detach 残差输入

这改变反向图而不是等价优化。前向通过后还须比较输入梯度，尤其要验证恒等通路仍存在。

广播掩盖了残差轴错位

用 B≠TB\ne TB=T⁠、各位置不同的测试值，逐元素比较；必要时明确 unsqueeze，避免把样本轴当成时间轴。

首步分支内部零梯度就认定断图

零门控或零末端投影可能有意让部分参数第一步不更新。先推导路径，观察门控/末端参数及第二步更新。
