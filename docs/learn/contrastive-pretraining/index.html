图文配对预训练是利用图像与文本之间的已知对应关系，训练二者的表示能够相互匹配的方法。CLIP 用双编码器与候选集合中的对比目标，SigLIP 用成对的 Sigmoid 目标；它们都不等同于把图文送入同一个融合网络。本章先定义正负关系与相似度，再推导损失和梯度，最后讨论这些全局匹配表示能为下游任务提供什么。

前置知识：概率、统计与训练目标 · 损失、掩码与归约 · 视觉编码器与多模态融合

本章学习目标

  • 构建图像—文本相似度矩阵和正确的配对标签。
  • 实现对称对比交叉熵，区分 Sigmoid 成对目标。
  • 解释温度、假负例及全局语义表征对精确读出的限制。

01配对关系与监督目标

正配对是数据中被声明相符的图像与文本，负配对是目标要求区分的不匹配关系。图文预训练将识别这些关系转化为学习信号，使两个编码器的表示可以比较。监督定义了何种对应被奖励，却未覆盖所有视觉属性。

图文对比学习从配对样本出发：图像编码器和文本编码器各输出一个向量，希望匹配对在相似度矩阵中更容易被识别。训练目标规定哪些对应关系被奖励，却不会自动告诉模型所有物理属性。描述中常出现的对象和属性可能被强调，未被描述的精细几何或操作状态可能缺少直接监督。理解特征为何可迁移，要从目标与数据覆盖开始，而不是只看骨干规模。

将一个 Batch 的 B 张图像与 B 条文本两两比较，得到 [B,B] 分数矩阵，通常对角线是本批给定的匹配关系。这个对角结构依赖数据保持顺序：独立 shuffle 文本后仍使用 arange(B) 作标签，会训练错误配对。不同数据可能一图多描述、一文本多图，原始的一一对角假设需要扩展，不能把所有非对角关系都无条件当成语义上互斥的负例。

先验证配对，再讨论温度或网络结构

相似度和交叉熵都能正常计算，但标签排列错误会优化完全不同的任务。

检查：打印图像 ID 与文本源 ID，做已知匹配/打乱配对对照，确认标签矩阵符合数据关系。

02相似度单位化、温度与梯度

向量单位化把特征缩放到单位长度，使点积只比较方向；温度或尺度再调节相似度差异进入损失时的强弱。前者约束表示，后者改变候选竞争或成对分类的数值尺度。下面分别追踪其梯度。

常见做法先将图像与文本向量按 L2 范数单位化，点积于是等于余弦相似度，再乘正尺度 s=exp⁡(α)s=\exp(\alpha)s=exp(α)⁠，或除以温度 τ\tauτ⁠。单位化减少模型仅靠放大向量范数提高分数的自由度，温度控制候选之间的区分强度。这里 α\alphaα 若是可学习参数，应明确是否实际优化其指数，并防止不合理尺度；不能把 logit_scale 本身和 exp(logit_scale) 混为一谈。

小温度使 Softmax 更尖锐，也会放大梯度尺度及对困难配对的关注；它不增加冻结特征中原本没有的可区分信息。若所有候选方向相同，单纯提高尺度不会让正确配对变得唯一。F.normalize 的 ε\varepsilonε 与零向量处理也应纳入数值检查。相似度分数并不能直接解释为可跨数据集比较的置信概率，候选集合与温度改变都会改变 Softmax 概率。

03双向交叉熵与尺度参数梯度

双向对比交叉熵分别把“由图找文”和“由文找图”作为候选分类任务，再合并两项损失。它们使用同一相似度矩阵，却沿不同轴归一化。先定义两个检索方向，再推导特征和尺度的更新。

图像到文本方向把 S 的每一行当成 B 类 logits，目标是同索引文本；文本到图像方向对 S 的转置做同样计算。两方向的平均要求每张图能找到其文本、每条文本也能找到其图像。虽然它们使用同一矩阵，但归一化分母分别沿行和列，不能只把某一个方向乘 2 当作对称目标。实现时 cross_entropy 接收原始 logits，不需要再先做 Softmax。

  2. 第一列的正确分数领先 1，第二列领先 3，因此文本到图像损失为 12[log⁡(1+e−1)+log⁡(1+e−3)]\tfrac12[\log(1+e^{-1})+\log(1+e^{-3})]21​[log(1+e−1)+log(1+e−3)]⁠。

04批内负例与候选集合

批内负例是利用同一批次其他样本构造的不匹配候选。候选集合决定模型当前需要区分谁，也决定 Softmax 的归一化分母。批次大小、重复描述和语义重合都会改变这个学习问题。

每个 Batch 给出 B 个正对和 B(B−1)B(B-1)B(B−1) 个非对角关系。更大的 Batch 通常引入更多候选，却不保证每个新增负例都有价值；重复描述和相近场景还可能产生假负例。B=1B=1B=1 时，对角 Softmax 的分母只有自己，交叉熵恒为零，这个目标无法提供区分配对的训练信号。单样本 loss 为零不能当作模型已经学会匹配。

多卡训练常汇聚不同 rank 的图文特征构造更大候选池，需要正确的全局标签偏移和梯度通信。简单把远端特征 detach 后拼接，是否得到想要的目标梯度取决于整体实现，不能只验证分数矩阵大小。教学代码的本地 B×BB\times BB×B 数值验证不等同于完整分布式实现验证。若队列或历史特征被用作负例，还应说明它们对应旧参数，和当前同批特征的更新机制不同。

B=1 的零损失不是学习成功

单候选 Softmax 概率固定为 1，梯度消失；这由目标结构决定。

检查：至少用两个不同配对构造可区分测试，并检查错配损失、梯度及全局标签偏移。

05Sigmoid 成对目标与归约分母

Sigmoid 成对目标将每个图文组合视为匹配与否的二分类，而不强制一行候选共享总概率。它与 Softmax 对比目标的归一化关系不同。下面先定义正负标签，再分析损失稳定形式与归约。

SigLIP 式目标可对每个图文对做二分类，正对符号 z=+1z=+1z=+1⁠、负对 z=−1z=-1z=−1⁠，用 softplus⁡(−z logit)\operatorname{softplus}(-z\,\mathrm{logit})softplus(−zlogit) 稳定计算负对数似然。它不要求每一行概率总和为 1；某图与多条文本的预测可同时较高。通常还需分数尺度与偏置，偏置有助于处理匹配对比例。不能只将 CLIP 的 Softmax 换成 sigmoid 而保持所有其他假设不变。

归约方式必须明确。若对 B2B^2B2 个配对求和后除以 B，与直接 mean 除以 B2B^2B2 相差 B 倍，梯度尺度不同；当 B 改变时，这个差异不是固定常数。负例采样、正负权重和偏置初始化也会影响目标。当前教学示例按 B 归约，用已知正负关系验证稳定计算，不试图复刻任意公开训练系统的全部配置。比较方法时应先统一实际优化的目标与计算预算。

  1. B=2B=2B=2 时有 4 个配对损失，假设它们总和为 8。
  2. 按 B 归约得到 4；对全部配对 mean 得到 2。
  3. B=4B=4B=4 时同一差异比例变为 4，而不是仍为 2。

分母是算法约定的一部分，不能把 loss 的数值缩放当成无关显示细节。

06假负例与两种多正例目标

假负例是语义上也相符、却被一一配对标签当成负例的组合；多正例目标允许一个查询对应多个正确候选。它们涉及监督关系的重新定义，而非只调整温度。下面比较两种多正例目标如何分配概率。

若两张图都符合“红色杯子”的描述，标准一一匹配目标仍可能把交叉配对当成负例，这是数据语义与监督标签之间的冲突。可考虑更清晰描述、多正例目标或过滤/权重策略，但这些都改变了训练问题，应明确比较。把标签简单全改为正例又会失去区分能力，不能作为通用修复。需要先理解数据中的等价关系与希望保留的细粒度差异。

“使用多正例”也不是唯一目标。设正例集合为 P、所有候选概率为 pjp_jpj​⁠。−log⁡ ⁣(∑j∈Ppj)-\log\!\left(\sum_{j\in P}p_j\right)−log(∑j∈P​pj​) 只要求总概率进入正例集合，一个正例吸收几乎全部质量也可得到低损失；−1∣P∣∑j∈Plog⁡pj-\frac1{|P|}\sum_{j\in P}\log p_j−∣P∣1​∑j∈P​logpj​ 则要求每个正例都分到概率。两个正例时，p=(0.99,0.01)p=(0.99,0.01)p=(0.99,0.01) 的前者为 0，后者约 2.31；p=(0.5,0.5)p=(0.5,0.5)p=(0.5,0.5) 的前者仍为 0，后者约 0.693。前者表达“任一个正确答案即可”，后者更接近“每个标注正例都应被检索到”；应由任务语义选择。

评估检索或迁移时，重复图像、相邻帧、同一原始样本的裁剪和描述变体可能跨集合泄漏。模型记住来源特征也能得到看似良好的配对指标，却未必学会任务所需概念。应按原始来源、场景或轨迹划分，并设计与目标泛化匹配的测试。图文匹配训练的成功还可能依赖水印、背景和固定模板，需要用内容替换、背景变化等对照判断捷径。

非对角不必然意味着语义错误

Batch 对角标签是一种数据假设；重复或等价描述会引入假负例。

检查：抽查高损失非对角对是否实际上匹配，保留原始来源 ID，按任务定义处理多正例关系。

07全局检索与下游表示

全局图文表示是把整幅图或整段文字汇总后的向量，适合比较整体匹配。局部动作任务还可能需要空间位置与细节。全局目标支持的能力，不能自动当成对每个 Patch 或控制变量的监督。

全局对比向量适合检索和某些分类，但动作模型可能需要局部位置、对象关系、历史状态或接触信息。将整图压成一个向量可能丢失细粒度结构；某层 patch 表征则可能保留更丰富空间线索，却没有被全局目标逐项验证。选择特征层、池化和条件接口需要下游对照，不能认为“来自强视觉编码器”就自动解决所有机器人观测建模。

线性探针、非线性适配、冻结或微调都是检查表示可用性的不同方式。小数据上适配失败，可能是信息不足，也可能是优化、尺度、标签或划分问题；成功则只证明在该评价设置下可用。后训练应同时检查新任务表现与既有图文能力，记录条件是否真正影响输出。对比 Loss 下降、检索提升和闭环成功率是不同指标，需分别给出证据。

08代表工作：CLIP、SigLIP 与 SigLIP 2

双编码器是分别编码图像与文本、再在共同空间比较输出的结构。CLIP、SigLIP 和相关变体在此基础上采用不同监督与训练设计。先明确共享结构，再逐项区分目标、特征与具体实现。

CLIP 和 SigLIP 采用双编码器：图像与文本分别编码，经过各自的汇聚与投影后，在共同特征空间比较全局向量。它们不是把图像和文本一起送入同一个融合 Transformer。视觉骨干与训练方法也是两个层次：原始 CLIP 同时研究了修改后的 ResNet 和 ViT，因此“使用 ViT”并不意味着“使用 CLIP 预训练”。

实际使用有两条路径。训练或适配图文检索模型时，保留图像塔、文本塔和匹配目标，数据要有可靠的配对关系；构建 VLM 或动作策略时，则可以只取预训练视觉塔，把未汇聚的视觉 Token 交给投影器和条件模型，再用问答、描述或动作监督适配。后一种做法不要求机器人数据重新附带 CLIP 式批内负例，也不等于从头训练图文编码器。是否冻结视觉塔，应作为下游训练方案的一部分验证。

例如，将“a photo of a red cup”和“a photo of a blue bowl”编码成两个候选向量，就能与一张图像的全局向量比较，形成零样本分类。这里的零样本指没有为这组下游类别另行训练分类头。CLIP 的候选 Softmax 会随候选集合变化；SigLIP 的逐对 Sigmoid 不要求这些分数和为 1，但其数值也受训练中的负例比例和偏置影响，不能直接解释成机器人任务成功概率。

接代码时还要核对返回值的处理阶段。OpenAI CLIP 实现的 encode_image / encode_text 返回投影后的特征，L2 单位化发生在计算匹配分数的 forward 中；自行缓存特征再算余弦相似度时仍需单位化。用于检索的全局向量与用于空间任务的视觉 Token 也不是同一输出，具体选择接续视觉与语言融合和视觉预处理。本章代码验证双向交叉熵和逐对 Sigmoid 的核心计算，不声称复现这些工作的完整预训练。

工作核心设计典型用途与使用边界
CLIP（2021）双编码器通过双向 Softmax 对比目标学习图文对应；文本可用来构造下游类别的比较向量。图文检索、文本定义的零样本分类，以及视觉塔初始化。完整模型输出匹配分数，并不自行生成图像描述或动作。
SigLIP（2023）将图文匹配写成含尺度与偏置的逐对二分类；归一化不依赖整行候选的 Softmax 分母，便于分块计算配对损失。仍可用于图文匹配和视觉表征迁移。逐对目标仍需要正负例；若枚举全部组合，配对数仍为批大小的平方，不能据此宣称没有负例成本。
SigLIP 2（2025）在 SigLIP 基础上加入描述/定位相关的解码器监督、多语言数据，并在标准分支加入自蒸馏与掩码预测；部分小模型还采用主动数据筛选。同时关注全局语义与局部表征，发布固定分辨率及 NaFlex 变体。论文 v1 的 NaFlex 分支未加入上述自蒸馏与掩码预测；训练用描述解码器也不包含在发布编码器中。下游效果需按任务验证。

09数值、梯度与语义对照

前面的定义把错误来源分成了配对关系、数值计算与表征学习三层。验证应按这个顺序推进，使每次实验只回答一个问题，再把局部计算的正确性与真实语义能力区分开。

第一层核对图文配对与矩阵轴；第二层检查单位范数、温度、logits 范围与稳定损失；第三层检查图像编码、文本编码和尺度参数的梯度；第四层做正误配对、重复描述和内容替换对照。纯合成相近向量应让正确配对损失低于打乱配对，但这种性质只验证实现，不代表真实图像与文字已经对齐。切勿把合成数据的高检索率作为预训练效果。

若训练不稳，先分别固定特征只优化尺度、固定尺度只优化编码器、缩小到可手算矩阵，定位问题来自目标还是表示。数值检查应覆盖零向量、极端分数和不同 B 的归约差异。将批次定义、正负例策略、分母、温度参数化与评价划分写入实验记录，才能让“CLIP 式”或“SigLIP 式”的名称对应到可复查的实际计算。

图文预训练先定义匹配关系，再通过编码、相似度与损失学习可比较的表示。候选竞争与成对分类是不同目标，全局匹配与局部控制也需要不同证据；这几层区别决定了怎样选择与使用预训练特征。
