推导与分析

先写出推导、计算或反例，再展开参考解核对假设与关键步骤。编程题位于下方，可从本页目录直接进入。

一个 Batch 中两张图像都是同一只红杯，文本也都写“红杯”。为什么只把对角线当正例可能有问题？

参考解与分析

非对角配对可能同样正确，却被单正例对比目标当作负例。模型会同时收到把语义接近的内容拉近与推远的信号；这不是简单的学习率问题。

应先核对配对语义与数据重复情况，再决定去重、组织 Batch 或使用多正例目标。不能因为两张图像像素不同就认定它们在当前文本任务中必须互为负例。

代码对应：检查 scores 的正例矩阵是否真的等于单位矩阵，尤其关注多相机同场景和重复描述。

  • 指出假负例来自标签假设，而不是矩阵维度。
  • 提出至少一种与数据语义一致的处理方式。

把相似度乘以更大的 exp(logit_scale) 会怎样？能否因此让冻结特征获得新的几何信息？

参考解与分析

尺度增大会改变 Softmax 的尖锐程度以及损失对相似度的梯度。它必须与特征单位化、正负例分布和训练稳定性一起考虑；过尖的分布也可能出现饱和或过度确信。

仅修改分数尺度不会给冻结特征增加原本没有编码的信息。它可能改善当前配对目标的数值行为，但不能替代下游监督、空间结构或任务能力检验。

代码对应：比较 scores、行概率和 logit_scale.grad；同时区分评分校准与表征内容变化。

  • 说清尺度是温度倒数方向：越大越尖锐。
  • 说明分数缩放不等价于增加可读出的几何信息。

所有候选余弦分数相同，提高 logit_scale 能让正例更容易被选中吗？如果存在多个正例，只优化它们的总概率是否要求每个正例都得高分？

参考解与分析

不能。共同乘正尺度后 logits 仍相同，Softmax 仍均匀，且 ∂L∂α=eα(∑jpjcj−c+)=0\frac{\partial L}{\partial\alpha}=e^\alpha\left(\sum_jp_jc_j-c_+\right)=0∂α∂L​=eα(∑j​pj​cj​−c+​)=0⁠。要区分候选必须改变表示或候选信息。

只优化 −log⁡ ⁣(∑j∈Ppj)-\log\!\left(\sum_{j\in P}p_j\right)−log(∑j∈P​pj​) 不要求正例之间均衡。两个正例的概率为 (0.99,0.01) 或 (0.5,0.5)，总质量都为 1，损失都为 0。平均正例交叉熵则分别约为 2.31 与 0.693，体现不同目标。

代码对应：固定余弦矩阵只对 α\alphaα 求导，再手算两个多正例归约。

  • 说明温度不能增加候选的可区分信息。
  • 区分“任一正例”与“每个正例”的概率要求。

参考实现
import math def symmetric_pair_ce(scores):    n = len(scores)    if n == 0 or any(len(row) != n for row in scores):        raise ValueError("需要非空方阵")    def lse(values):        m = max(values)        return m + math.log(sum(math.exp(x-m) for x in values))    row_loss = sum(lse(row)-row[i] for i, row in enumerate(scores))    col_loss = 0.0    for i in range(n):        column = [scores[j][i] for j in range(n)]        col_loss += lse(column)-scores[i][i]    return (row_loss+col_loss)/(2*n)

非对称矩阵测试会识别把同一个行损失算两遍的错误。温度已包含在输入分数中，本函数只负责配对监督。

辨析与纠错

判断下面的说法或实现会在哪一步失效，并说明成立所需的条件，再展开分析核对。

传入已经 Softmax 的分数给 cross_entropy

该接口需要 logits，重复归一化改变目标。用 2×2 手算矩阵核对交叉熵。

图文独立打乱后仍使用对角标签

损失能下降但学习了错误配对。携带原始 ID，核对每一行的正确候选索引。

把所有非对角项都解释为真正负例

重复描述与等价场景可能是多正例。检查高损失对并按任务定义处理，避免无意识地制造监督冲突。

Sigmoid 目标的 sum/B 与 mean 随意替换

二者相差 Batch 大小倍数，改变 B 时梯度尺度也不同。明确配对数、正负权重与归约口径。

靠增大 logit_scale 修复冻结特征信息不足

尺度只改变已有相似度的区分强度。用内容干预和下游验证判断表示是否包含需要的信息。
