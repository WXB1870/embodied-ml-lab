为什么条件 score 不等于边际 score，却可以作为训练目标？

参考解与分析

同一个 xxx,ttt 可能来自多个干净样本与噪声配对。边际 score 是条件 score 在这些隐藏配对后验下的平均。

平方误差将目标分解为到条件均值的模型误差与独立于模型参数的条件方差，因此共享总体最优解；单样本梯度仍然不同。

代码对应：mixture 函数的 rho、clean_mean 与 noise_mean；先固定条件 c，再对分量作后验平均。

  • 写出边际密度求导
  • 指出后验权重
  • 说明总体等价与随机梯度的差别

相同边际密度为什么允许 SDE 在运动、ODE 却静止？

参考解与分析

平稳高斯的随机扩散与收缩漂移可以互相抵消，使密度不变，但单条随机轨迹仍在变化。

概率流把密度的净变化写成确定性通量；在这个例子中该通量为零，因此 ODE 保持每个初值。相同边际不等于相同路径分布。

代码对应：完整代码末尾 stationary_score 的符号检查与 reverse_vp_step 的第一项测试。

  • 计算两个漂移
  • 解释扩散平衡
  • 区分边际与路径

同一个二维数据分布同时使用线性 FM 与 VP 路径，为什么不能直接比较两种网络的原始 MSE，或认定同一初始噪声会得到同一终点？

参考解与分析

固定状态、时间和同一路径时，噪声误差换成速度误差会乘 (σ˙−α˙σ/α)2(\dot\sigma-\dot\alpha\sigma/\alpha)^2(σ˙−α˙σ/α)2⁠。改变路径还改变训练状态分布，因此原始 MSE 的单位、时间权重和输入分布均可能不同。

两种精确场可以产生相同终点边际，但不必实现相同的端点耦合。共享初始噪声适合做受控计算，却不能把逐点终点差直接解释为哪一种生成分布更差。

先固定数据、条件和评价分布，再分别报告路径、预测目标、时间采样、NFE 和数值误差；有限训练观察不升级为方法优劣定理。

  • 说明共享数据不等于共享中间分布。
  • 给出同一路径参数化误差的时间系数。

参考实现与说明

参考实现
import math def reverse_vp_step(x, score, h, beta, noise):    values = (x, score, h, beta, noise)    if not all(math.isfinite(float(v)) for v in values) or h <= 0 or beta < 0:        raise ValueError("finite values, h>0 and beta>=0 are required")    # h advances tau=T-t, so the forward-time drift changes sign.    ode = x + h * (0.5 * beta * x + 0.5 * beta * score)    sde = x + h * (0.5 * beta * x + beta * score) + math.sqrt(beta*h) * noise    return ode, sde

两个方法的差异同时包含漂移和随机项；删除 SDE 噪声而不改变漂移不是概率流 ODE。测试中的平稳高斯反例可以直接发现这一错误。

辨析与纠错

判断下面的说法或实现会在哪一步失效，并说明成立所需的条件，再展开分析核对。

把 score 理解成某个样本的概率大小

Score 是状态方向上的 log 密度梯度，维度与样本相同。它不能单独替代归一化密度或 log_prob，连续流求密度还需要相应的散度积分与初始密度。

忽略反向时钟导致两次变号

使用下降的前向时间 ttt 与使用上升的 τ=T−t\tau=T-tτ=T−t 是两套等价约定；目标时间、漂移符号和步长必须整体匹配。

从反向 SDE 删除随机项就称为概率流 ODE

反向 SDE 的 score 修正系数是 g2g^2g2⁠，而概率流 ODE 是 g2/2g^2/2g2/2⁠；随机扩散对密度演化的贡献不能凭空消失。

把所有 velocity 名称当成相同参数化

线性 FM 的端点差、一般仿射路径的时间导数、VP 的角度 vvv 参数化都依赖不同定义。应从路径系数及导数进行转换，端点也可能不可逆。

用更多积分步数修复错误模型

细化同一个场只减少相应数值误差，不保证修复 score/velocity 偏差、条件缺失或终端先验失配；三类误差应做分离实验。
