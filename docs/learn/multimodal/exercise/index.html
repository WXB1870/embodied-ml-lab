推导与分析

先写出推导、计算或反例，再展开参考解核对假设与关键步骤。编程题位于下方，可从本页目录直接进入。

为什么把纯视觉 token 平均池化后，接一个从未接收文本的分类器，不能期待它按不同文本条件给出不同类别判断？

参考解与分析

如果图像、参数和其他输入完全相同，而语言没有进入任何上游特征或读出计算，读出头接收的输入就相同，确定性输出也应相同。扩大头或训练更久不会补足缺失的条件通路。

如果取的是已经与语言交互后的 VLM token，则其表示可能包含任务信息，但仍需要指令替换实验验证。要先确认特征提取位置，再判断池化和小头是否保留了可用的任务条件。

代码对应：从分类 loss 反向追踪文本输入的计算依赖，固定图像只改变文本做对照。

  • 指出计算图中必须存在语言条件路径。
  • 区分纯视觉特征与已融合语言的 VLM 特征。

多相机视觉 token 直接求平均隐含了什么权重？Padding 与不同相机 token 数怎样影响结果？

参考解与分析

直接对全部 token 平均，相当于每个 token 权重相同，因此 token 更多的相机在总向量中占更大比例。它不是自动按相机等权，也不能自动恢复各相机的几何关系。

Padding 应通过显式有效位排除，并用有效 token 数作分母。若希望相机等权，可以先按每个相机的有效 token 池化再融合，但缺失视角与不同质量视角仍需定义策略并评估。

代码对应：分别统计每个视角 N、有效位和最终池化分母，确认设计的权重口径。

  • 说明 token 等权不等于相机等权。
  • 明确 Padding 同时从分子和分母排除。

视觉特征从 256 维投影到 2048 维后，为什么仍不能保证恢复压缩前的空间细节？怎样区分表示瓶颈与优化失败？

参考解与分析

线性投影 W 的秩最多为 256，增加输出坐标数不能新增独立输入信息。更一般地，两张图若编码后 z 完全相同，任意只读取 z 的确定性网络都给相同输出。

可先构造只改变目标所需空间关系的输入对，比较压缩前 token 与压缩后表示。如果在目标不同的输入上压缩后完全相同，已能证明该接口无法完成区分；若表示不同，则尚不能断言可容易学出答案，仍可能有优化、标签或数据问题。

代码对应：对成对输入分别记录 token、池化向量和 projector 输出；避免只比较 shape。

  • 用相同表示必有相同输出的论证解释不可恢复。
  • 不把宽度增加等同于新增信息。

一个带 4 个 Register 的 DINOv2 编码器接收 224×224 图像，Patch 大小为 14，输出 [B,261,D]。请写出 CLS、Register、Patch 的切片及恢复空间特征图的过程。为什么不能仅根据 N 开平方推断网格？

参考解与分析

在本章核验的排列下，CLS 为 Z[:,0]，Register 为 Z[:,1:5]，Patch 为 Z[:,5:]，其数量是 16×16=256。先转置为 [B,D,256]，再按已知行优先顺序恢复为 [B,D,16,16]。应断言总数与 1+4+16×16 一致。

完整 token 数含非空间位置，开平方没有网格意义；即使只取 Patch，非方形输入也可能产生非方形网格。同一个数量还可能对应不同长宽组合，必须保留编码器实际使用的网格元数据。

代码对应：独立实现代码页中的 split_visual_tokens，再用 2×3 网格、0/4 个 Register 和错误元数据验证；额外检查一个明确的行列位置。

  • 明确三个切片的边界并核对 261=1+4+256。
  • 维持行列对应关系，不依赖 sqrt(N) 或静默丢弃多余 token。

要将 CLIP、DINOv2 或 MAE 编码器接到同一个策略头，只要把通道投影成相同宽度就能公平比较吗？

参考解与分析

相同宽度只约束张量接口。还要固定或记录输入分辨率、预处理、所取层、特殊 token、空间 token 数、池化与归一化，以及是否微调编码器。全局匹配向量与空间 token 即使投影到同一宽度，仍可能丢失不同的信息。

在一致的数据切分、动作表示、策略头和训练预算下做受控比较，并报告任务相关指标。文本检索、像素重建或图像分类的表现不能替代闭环任务成功率；需要根据模型预训练目标提出假设，再用实验检验。

代码对应：保存各候选模型的输出约定和预处理配置，对相同输入记录实际 shape；设计仅替换视觉表示的对照实验。

  • 区分骨干结构、预训练目标、输出接口和任务头。
  • 不将语义匹配能力直接等同于空间精度或策略表现。

参考实现
def pack_multiview(text_tokens, cameras):    packed = list(text_tokens)    spans = []    for camera in cameras:        start = len(packed)        packed.extend(camera)        spans.append((start, len(packed)))    return packed, spans

索引范围是调试多模态可见性和可视化注意力的基础；丢失来源信息后，难以确认读出内容的来源。

辨析与纠错

判断下面的说法或实现会在哪一步失效，并说明成立所需的条件，再展开分析核对。

把任何 [B,N,D] 都当成同一种 VLM 表征

确认层位置、是否融合文本、位置与归一化状态。形状相同不能证明信息或条件相同。

只加视觉 Projector 就期待输出跟随文本

若语言未进入计算图，确定性输出不会因未使用的指令改变。沿损失反向追踪条件路径，并做文本替换对照。

平均所有 token 但没有处理来源数量与 Padding

先定义 token 等权还是图像等权，再同时修正有效分子与分母；全无效情况应显式处理。

冻结参数后无条件包住整个 no_grad

若前面有可训练模块，需要梯度穿过冻结网络。分别检查参数梯度和输入梯度，不能用冻结状态替代依赖分析。

用合成例子的梯度通过宣称模型具备视觉理解

教学例子只验证接口和计算。真实迁移需预训练权重、匹配预处理、独立数据与任务评价。
