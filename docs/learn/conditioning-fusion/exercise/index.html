推导与分析

LayerNorm 自带的 gamma/beta 与 FiLM 或 AdaLN 由条件生成的参数有什么区别？为什么 [B,D] 要变成 [B,1,D]？

参考解与分析

标准 LayerNorm 的可学习仿射参数通常跨样本和位置共享；FiLM/AdaLN 的调制参数由当前样本的条件产生，因此不同指令、状态或生成时间可以得到不同的缩放与平移。二者在计算中承担不同角色。

输入是 [B,T,D] 时，在中间增加长度一的轴，让条件只沿该样本的 T 个位置广播。不能用维度碰巧相等来判断正确性，应该选择 B 与 T 不同的例子，并只改变一个样本的条件检查隔离。

代码对应：检查 modulator 输出的分块顺序，以及 scale[:,None,:] 和 shift[:,None,:] 的轴。

  • 区分共享的固定参数与样本条件产生的动态参数。
  • 解释时间轴广播并给出样本隔离检查。

残差门控初始化为零时，条件输入或分支内部梯度为零，一定表示代码断图吗？输出随指令改变是否已经证明语言跟随正确？

参考解与分析

不一定。y = x + gate * F(...) 的乘法结构使 gate=0 时部分分支梯度为零，但门控生成层仍可能获得梯度。应检查门控参数的梯度、完成更新后再观察分支，而不是要求首步所有参数都有非零梯度。

输出随指令变化只证明计算路径对条件敏感。它也可能是无意义的数值变化；需要固定场景和其他条件，使用明确的指令—目标对照评估，检查动作是否按语义改变以及错误率如何变化。

代码对应：同时观察 gate 相关参数梯度、更新后的条件梯度，以及任务层面的指令干预结果。

  • 能用乘法路径解释首步零梯度。
  • 明确区分条件敏感性与正确语言跟随。

单层“拼接后 Linear”和 FiLM 都输出相同形状，为什么它们对输入—条件交互的表达不同？

参考解与分析

拼接后 Linear 为 Wxx+Wcc+bW_x x+W_c c+bWx​x+Wc​c+b⁠，对 x 的 Jacobian 恒为 WxW_xWx​⁠，与 c 无关；混合二阶导数为零。条件只能改变偏置项。

FiLM 为 γ(c)⊙x+β(c)\gamma(c)\odot x+\beta(c)γ(c)⊙x+β(c)⁠，对 x 的 Jacobian 是 diag⁡(γ(c))\operatorname{diag}(\gamma(c))diag(γ(c))⁠，会随条件变化。若 γ(c)=Ac+b\gamma(c)=Ac+bγ(c)=Ac+b⁠，混合二阶导数直接给出 A 的元素。

FiLM 本身仍仅逐通道缩放，并非任意动态矩阵。带非线性的拼接网络也能学习交互，不能把单层反例推广成拼接永远不如 FiLM。

代码对应：固定条件后比较输出对 x 的 Jacobian，再改变条件观察这个 Jacobian 是否变化。

  • 给出两种结构的 Jacobian。
  • 明确结论只针对所讨论的层及其非线性假设。

参考实现与说明
参考实现
def film_batch(features, gamma, beta):    if len(features) != len(gamma) or len(features) != len(beta):        raise ValueError("Batch 大小不一致")    result = []    for batch,row_list in enumerate(features):        if len(gamma[batch]) != len(beta[batch]):            raise ValueError("条件通道不一致")        rows = []        for row in row_list:            if len(row) != len(gamma[batch]):                raise ValueError("特征通道不一致")            rows.append([gamma[batch][d]*value+beta[batch][d]                         for d,value in enumerate(row)])        result.append(rows)    return result

第二个样本的第二通道 gamma 为零，所以输出始终等于 beta=4。改变第一个样本的条件不应影响第二个样本。

辨析与纠错

判断下面的说法或实现会在哪一步失效，并说明成立所需的条件，再展开分析核对。

有条件输入就认为模型使用了条件

Mask、池化、detach 或数据捷径都可能让条件失效。分别检查计算路径、条件干预和任务级语义指标。

直接 γ 与 1+scale 的初始化混用

直接 γ=0\gamma=0γ=0 会抹掉特征，1+scale 在 scale=0 时才保留特征。根据公式设置初始化并明确无调制参考。

只用 B=T 的张量测广播

相同维度可能让错误轴静默对齐。用不同 Batch 和时间长度，并确认改单个样本条件不会影响其他样本。

将首步零梯度一概归为断图

乘法门控与零初始化能够产生预期零梯度。先检查门控梯度及一次更新后的路径，再决定是否存在 detach。

用随机输出变化证明语言理解

变化只能说明数值敏感，不能说明方向正确。固定场景和噪声，设计目标明确的指令对照并评价任务结果。
