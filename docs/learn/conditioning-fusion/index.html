条件注入是让模型的计算依赖额外已知信息的方法，例如用图像、语言或生成时间改变动作预测。拼接直接提供条件特征，Cross-Attention 从条件序列读取内容，FiLM 和 AdaLN 则用条件调制特征通道。它们建立不同形式的交互。本章先定义条件的信息路径，再比较这些机制，最后检验条件怎样影响前向、梯度与缓存。

前置知识：归一化：统计轴、梯度与不变性 · 残差连接与深层优化 · 注意力：匹配、聚合与梯度

本章学习目标

  • 区分特征拼接、token 拼接、Cross-Attention 与逐通道调制。
  • 实现条件生成的缩放和平移，并检查广播轴。
  • 解释零门控初始化时的梯度现象与语义验证边界。

01条件依赖与信息路径

条件模型在当前待处理对象之外，还以已知信息 c 决定输出。条件路径是这些信息进入运算并影响预测的依赖关系。输入接口有某个字段，只证明数据被传入，尚未证明计算或训练实际使用了它。

条件模型写成 fθ(x,c)f_\theta(x,c)fθ​(x,c)⁠：x 是当前需要处理的状态或 token，c 是语言、视觉、状态或生成时间等条件。输入字典里出现 c 不代表输出依赖 c；真正的信息路径可能被 Mask 遮住、被 detach 截断，或在训练中被权重忽略。先写出每个条件通过哪条算子路径影响哪个输出，才能讨论融合是否有效。

不同条件具有不同结构。一个生成时间标量可以编码成向量，一条语言指令含有词序，多张图像包含空间位置。把所有条件都平均成一个向量会降低接口成本，也会丢失局部检索能力；保留全部 token 增加灵活性，同时增加注意力开销。接口选择应对应任务所需信息，而不只是为了拼接时 shape 匹配。

还要区分条件的时间含义：序列位置描述“第几个 token”，动作时间描述“预测哪个执行时刻”，生成时间描述“当前噪声或流状态”。三者可能同时进入一个模型。把它们统一称为 t 而不注明尺度和来源，容易造成训练和采样使用不同条件的错误。

02特征拼接与 token 拼接

特征拼接沿通道轴并排提供不同信息，Token 拼接沿位置轴增加可被读取的序列项。二者分别改变一个位置的内容与整组候选位置。下面先看连接后由什么算子完成交互。

特征拼接将 x∈RDx\in\mathbb R^Dx∈RD 与 c∈RCc\in\mathbb R^Cc∈RC 合成 [x;c][x;c][x;c]⁠，单个线性层给出 Wxx+Wcc+bW_x x+W_c c+bWx​x+Wc​c+b⁠。对每个 token 复制同一个 c 时，条件相当于样本相关偏置；输入与条件的混合二阶导数为零，条件不能改变该层对 x 的线性斜率。随后加入非线性或更深结构可以产生交互，因此这个限制属于“拼接后只有一个线性层”，不是对所有拼接网络的限制。

Token 拼接沿序列轴加入条件，通常需要先将宽度投影到共同 D，并补上位置或来源信息。要让动作 token 读取条件，Mask 必须开放相应方向；若条件放在因果序列的未来，较早的动作位置无法看到它们。即使开放了一层，也要检查其他层或池化操作是否保留了这条路径。

条件 token 与动作 token 一起进行自注意力，可能让条件表示也反向读取动作。这个设计可以有用，但会影响固定前缀缓存是否成立。选择融合方式时，应同时考虑表示能力、可见性、计算量和后续推理复用，而不只比较 API 调用是否简短。

03Cross-Attention 与单个条件 token

Cross-Attention 让待更新位置发出 Query，读取条件序列提供的 Key/Value。多个条件位置允许按内容选择；若只剩一个有效条件位置，Softmax 权重恒为一。这个边界决定条件压缩后还剩什么交互。

Cross-Attention 用需要更新的 token 生成 Q，用条件序列生成 K/V。每个查询获得不同权重，因此多个动作位置可以关注不同词或图像 patch；输出长度由查询数决定，不由条件长度决定。若条件仅压缩成一个 token，则每个头对唯一有效键的 softmax 权重为一，无法再在多个条件位置之间选择。

只有一个有效 Key 且无注意力 Dropout 时，softmax⁡([s])=[1]\operatorname{softmax}([s])=[1]softmax([s])=[1]⁠，读出就是 V，完全不依赖 Q 或 K。这条注意力分支对 Q/K 的梯度为零；Value、输出投影仍可学习，若外面有残差，整个块仍可依赖查询输入。把整幅图先压成一个 token 后，不能再期待 Cross-Attention 根据不同查询从图内不同位置进行选择。

条件键的 padding 或缺失视角要被正确遮罩。给每个查询增加相同条件向量，与让每个查询根据内容读取一组条件 token，表达方式不同；后者仍可能忽略条件，因此结构选择不能代替任务验证。可检查交叉注意力输出、条件扰动和最终损失的变化，但不要把漂亮的权重热图直接解释成因果证据。

条件宽度与动作宽度可以不同，通过各自投影进入同一每头维度即可。多头 attention 的头数、条件序列长度、query 长度也不是同一个概念。阅读代码时先给 Q/K/V 标注 [B,H,Tq,d]、[B,H,Tc,d]，再检查 Mask 在哪条轴上表示有效条件。

先画可见性，再决定是否能缓存条件

条件 token 是否读取动作会影响它在迭代中是否变化；只要输出 shape 相同，双向与单向信息流都能运行，却有不同语义。

检查：固定 c、改变 x，比较各层拟缓存条件 K/V；同时验证动作查询确实能读取有效条件，不能读取 padding。

04FiLM 的乘法交互与通道限制

FiLM 是由条件生成逐通道缩放与平移、再作用于中间特征的调制方法。缩放引入条件与特征的乘法关系，平移改变响应的偏移。它不直接在不同位置之间检索内容，表达机制与注意力不同。

FiLM 用一个条件网络生成 γ(c)\gamma(c)γ(c)⁠、β(c)\beta(c)β(c)⁠，再做 γ⊙h+β\gamma\odot h+\betaγ⊙h+β⁠。它显式引入条件与特征的乘法：条件可以放大、压低或翻转某个通道，平移则改变非线性前的阈值。这里的参数通常是逐通道向量，不是整层共享的一个数；也不能把 γ\gammaγ 固定看作概率，因为它不必位于零到一。

若 γ(c)=Ac+b\gamma(c)=Ac+bγ(c)=Ac+b⁠，则 yi=(Aic+bi)hi+βi(c)y_i=(A_ic+b_i)h_i+\beta_i(c)yi​=(Ai​c+bi​)hi​+βi​(c)⁠，有 ∂2yi∂hi ∂cj=Aij\frac{\partial^2 y_i}{\partial h_i\,\partial c_j}=A_{ij}∂hi​∂cj​∂2yi​​=Aij​⁠。条件直接改变输入通道的局部斜率，这就是它与单层线性拼接的机制差别。不过对固定条件，FiLM 对 h 的矩阵仍是 diag⁡(γ(c))\operatorname{diag}(\gamma(c))diag(γ(c))⁠，不能单独实现任意通道旋转；前后线性层可以提供通道混合，不应把逐通道门控描述成任意条件线性变换。

对于 h=[B,T,D]，每样本条件给出 [B,D]，需要变为 [B,1,D] 才能沿时间轴广播。直接相乘时 PyTorch 从右侧对齐维度；若恰好 B=TB=TB=T⁠，错误表达式甚至可能静默把样本条件当作时间条件。用 B≠TB\ne TB=T 和逐样本干预，才能暴露这个错位。

FiLM 不要求必须先归一化，但应用位置会改变行为：在线性层前后、激活前后调制不是同一函数。若条件本身是逐 token 的，调制也可以是 [B,T,D]，此时无需跨 T 共享。实现时应明确调制粒度，而不是见到两个相同维度就自动加广播。

FiLM(h,c)=γ(c)⊙h+β(c)\mathrm{FiLM}(h,c)=\gamma(c)\odot h+\beta(c)FiLM(h,c)=γ(c)⊙h+β(c)

05AdaLN 与条件仿射

自适应 LayerNorm（AdaLN）在 LayerNorm 之后使用条件生成的缩放和平移。它先调整特征统计，再依据条件调制通道，因而不同于固定仿射参数的 LayerNorm。下面比较其初始化与广播关系。

AdaLN 在 LayerNorm 之后施加条件生成的缩放和平移，常写为 (1+s(c))⊙LN⁡(x)+b(c)(1+s(c))\odot\operatorname{LN}(x)+b(c)(1+s(c))⊙LN(x)+b(c)⁠。加一是参数化选择：s=b=0s=b=0s=b=0 时得到 LN(x)，便于把“无调制”作为初始化点。若使用直接 γ\gammaγ 参数化，则无调制对应 γ=1\gamma=1γ=1⁠、β=0\beta=0β=0⁠；不能从一种公式复制零初始化到另一种公式。

常见实现关闭 LayerNorm 自带的 elementwise_affine，让动态调制负责仿射，避免额外共享 γ\gammaγ⁠、β\betaβ 混淆解释；保留共享仿射也可以，但那是另一种参数组合。LayerNorm 的统计轴仍是最后的通道 D，条件不应该让不同样本混在一起求均值方差。

FiLM 与 AdaLN 的关键区别不是名字，而是被调制的特征是否先归一化及如何参数化。LN 去掉部分均值/尺度信息，条件仿射再引入样本相关的变化。若任务需要原始幅度或绝对统计，可以由残差路径或独立条件保留，不能期待归一化后的表示无条件保存所有原信息。

AdaLN(x,c)=(1+s(c))⊙LN(x)+b(c)\mathrm{AdaLN}(x,c)=(1+s(c))\odot\mathrm{LN}(x)+b(c)AdaLN(x,c)=(1+s(c))⊙LN(x)+b(c)

06零门控残差与首步梯度

零门控残差在变换分支外乘一个初始为零的门控，使整个块初始返回输入。门控、调制参数和分支参数可能在首步获得不同梯度。先看完整连接，才能判断“初始不改变输出”究竟限制了谁的学习。

在调制分支外再乘 gate，可以得到 y=x+g(c)⊙F ⁣(AdaLN⁡(x,c))y=x+g(c)\odot F\!\left(\operatorname{AdaLN}(x,c)\right)y=x+g(c)⊙F(AdaLN(x,c))⁠。g=0g=0g=0 时整个残差块输出等于 x，尽管内部 F 的输出不为零。这与 s=b=0s=b=0s=b=0 只保证 AdaLN 等于 LN(x) 不同：无调制不等于整个块恒等，恒等需要残差分支的总体贡献为零。

由链式法则，分支内部参数梯度含 g 因子，因此首步 g=0g=0g=0 时通常为零；门控梯度则含 F 的当前输出，可以非零。如果生成所有调制参数的最后线性层权重为零，条件输入的梯度也可能为零，即使门控偏置正在学习。不能把这些预期零值误判为 detach。

也要避免把所有相关项都同时清零而造成死分支。例如 F 输出和门控都为零时，门控梯度与 F 内部梯度都可能为零，需要检查实际初始化。DiT 的 AdaLN-Zero 是具体的结构与初始化设计，不是“任何层全部设零都会更稳定”的通用规则。

例：用标量残差手算零门控的两条梯度

  1. 取 y=x+gwxy=x+gwxy=x+gwx⁠，x=3x=3x=3⁠、w=2w=2w=2⁠、g=0g=0g=0⁠，并令上游 ∂L∂y=1\frac{\partial L}{\partial y}=1∂y∂L​=1⁠，则前向 y=3y=3y=3⁠。
  2. ∂L∂w=gx=0\frac{\partial L}{\partial w}=gx=0∂w∂L​=gx=0⁠；∂L∂g=wx=6\frac{\partial L}{\partial g}=wx=6∂g∂L​=wx=6⁠。内部 w 首步不更新，门控却可以离开零点。
  3. 如果再令 w=0w=0w=0⁠，则门控梯度也为零；若 g=acg=acg=ac 且 a=0a=0a=0⁠，条件 c 的梯度同样为零，但 a 的梯度还可能非零。

检查结构预期、门控参数和更新后梯度，比要求所有参数首步非零更准确。

无调制、恒等块与条件有梯度是三件事

s=b=0s=b=0s=b=0 只还原 LN；g=0g=0g=0 才让残差贡献为零。零门控或零调制权重会让部分梯度暂时为零，不能统一视为断图。

检查：先核对初始输出等于谁，再打印 gate 参数梯度；完成一次有效更新后重新检查分支与条件输入的梯度。

07时间编码与多条件组合

时间编码将生成阶段转换为网络可使用的特征，多条件组合则规定时间、观测与其他信息在哪些位置共同影响计算。它们需要各自明确取值与语义，再决定拼接、读取还是调制。

生成时间可先经多频正弦/余弦映射，再由 MLP 生成调制向量，使网络能够在不同频率上表示随时间变化的规律。训练用 [0,1] 而推理输入 [0,1000]，即使维度一致也会让编码处于不同区域；方向、范围与端点定义需要和噪声或 Flow Matching 的路径约定一致。

多个条件可以先各自编码到同一宽度后求和，也可以拼接再投影。求和成本低，但两路的尺度和识别方式需要学习；拼接保留显式槽位，增加后续参数。任一种方式都需要考虑缺失条件的表示，不能把“无指令”临时替换为不曾训练过的随机向量。

若使用条件丢弃训练无条件路径，丢弃粒度与空条件表示应和推理一致。仅在推理时把 c 置零，并不能保证模型学会无条件函数。条件有多个来源时，还应明确丢弃整组还是只丢一部分，避免所谓无条件分支仍通过其他编码或缓存读取同一信息。

08条件干预与语义评估

输出随着条件变化，只说明存在依赖，尚不能说明模型理解了条件的语义。验证需要从形状和梯度推进到受控干预，最终检查输出是否朝任务要求的方向改变。

第一层验证结构：断言调制参数形状、归一化轴、广播方向和残差初始行为，检查有效条件确实有路径到输出。第二层验证数值：在 eval 下固定输入和随机噪声，只改变一条样本的一个条件，检查对应输出变化以及其他样本不变，并按初始化预期检查梯度。

第三层验证语义：同一场景配两条要求不同结果的指令，评价输出是否朝正确目标改变，而不只是某个数不同。打乱语言与样本配对、移除条件或替换为无关条件，可以帮助判断模型是否依赖它；这些消融的性能差异还需结合数据相关性解释，不能把任意下降都归为良好语言理解。

示例在零门控初始化后手动赋予非零参数，用于观察计算路径与样本隔离；语言理解仍需任务指标检验。真实训练中应观察门控分布、条件梯度、行为指标及不同条件组合的泛化。结构教学和能力结论分开，才能避免从一个通过 assert 的小例子推导过大的结论。

这些局部算子怎样在完整动作模型中组合，见 VLA 模型架构：图像、语言与状态如何进入 token，Action Expert 如何读取条件，以及冻结与缓存如何改变梯度。该课分别标明具体 OpenPI 版本和教学实现，避免将单一融合方式视作所有 VLA 的共同结构。

条件注入的关键是能够指出“条件在何处改变了哪项计算”。拼接、检索与调制分别提供不同交互；只有同时核对前向依赖和反向路径，才能把结构接入、条件敏感性与语义利用区分开。

FiLM 的条件仿射变换

FiLM 的一个通道：y = γh + β。灰线是恒等映射，蓝线由条件生成的 γ、β 决定；多个样本应各自使用自己的条件。

对 [B,T,D] 特征，按样本和通道生成的 γ/β 通常为 [B,1,D]；这是一种条件接口，并不自动保证模型理解了条件语义。AdaLN 则在归一化后的特征上做类似调制，具体实现可能用 1+scale。
