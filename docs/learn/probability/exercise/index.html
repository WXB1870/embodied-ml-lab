CrossEntropyLoss、log_softmax 和 NLLLoss 的输入分别是什么？为什么不应先 softmax 再传 CrossEntropyLoss？

参考解与分析

类别索引监督下，CrossEntropyLoss 接收未归一化 logits；log_softmax 把 logits 变成对数概率；NLLLoss 接收对数概率并选取正确类别。log_softmax 与 NLLLoss 的组合对应交叉熵。

先 softmax 再传 CrossEntropyLoss 会把概率误当作新的 logits，再归一化一次，损失与梯度都改变。代码用 logsumexp−正确分数独立还原目标，并检验共同平移 logits 后结果不变。

代码对应：categorical_nll 的 logsumexp/gather；演示 F.log_softmax 与 F.cross_entropy 对照。

  • 能说明三个接口的输入空间。
  • 能解释重复 softmax 改变了函数，而不只是多做一次计算。

MSE 的条件均值结论在加权、标准化和缺失标签下还成立吗？

参考解与分析

普通平方误差的最优值是 E[Y|x]。使用非负数据权重后，应重新求导得到 E[wY|x]/E[w|x]；若 w 只由 x 决定且非零，固定 x 时会抵消。若权重偏向某类标签或成功轨迹，通常会改变最优均值。

固定的逐维正尺度 sds_dsd​ 对误差施加 1sd2\frac1{s_d^2}sd2​1​ 权重。对不受限制的向量预测，每一维的最优条件均值仍不变；对共享参数、有限容量的模型，各维竞争以及优化轨迹却可能改变。必须区分统计最优解与受限制模型的训练结果。

只在标签有效处训练时，学到的首先是所观察标签分布下的目标。只有在给定 x 后有效性不再依赖 Y 等相应条件下，才可以把它解释成未筛选总体的条件均值。Mask 解决了参与计算的问题，不会自动修复选择偏差。

代码对应：平方误差展开与加权最优值；losses 课程中的有效分子、分母。

  • 能推导加权条件均值，而不只背诵 MSE 的结论。
  • 能区分权重依赖输入、标签和模型参数三种情况。

实现数值稳定的 softmax

输入非空 logits 列表，输出概率列表。必须能处理 [1000,1001,999]，并且整体平移 logits 后结果不变。 输入元素保证为有限实数；返回列表与输入等长。空列表应抛出 ValueError。

参考实现与说明

参考实现
import math def stable_softmax(logits):    if not logits:        raise ValueError("logits 不能为空")    maximum = max(logits)    exps = [math.exp(z - maximum) for z in logits]    total = sum(exps)    return [value / total for value in exps]

减最大值没有改变概率比值，却避免了正方向指数溢出；非常小的概率仍可能下溢，这是有限精度的限制。

辨析与纠错

判断下面的说法或实现会在哪一步失效，并说明成立所需的条件，再展开分析核对。

把概率密度当成离散概率

连续变量在单点的概率为零，密度可以大于 1，负对数密度也可能为负。不要把回归分布的 NLL 数值直接套入分类概率的直觉。

向 CrossEntropyLoss 传 Softmax 结果

接口会再次对输入做对数归一化，得到另一目标。训练时传 logits；需要展示概率或采样时再显式转换。

KL 参数位置和数学方向反了

先写目标 DKL(p∥q)D_{\mathrm{KL}}(p\Vert q)DKL​(p∥q)⁠，再确定教师 p 与学生 q 各由哪个参数提供。检查 target 是否概率、input 是否对数概率，以及 reduction 的分母。

同条件多种动作却只看平均误差

平均预测可能位于多个模式之间。检查条件信息是否充分，并用样本分布和真实任务指标判断是否需要分布式输出或生成式建模。
