多任务训练让多个目标共同更新一组共享参数；任务梯度是每个目标在这组参数上的导数，合成梯度由任务权重与采样共同决定。梯度点积可以解释局部相互作用，却不直接等于长期迁移收益。本章先定义共享坐标与加权目标，再推导一阶关系、读取各任务梯度，最后用独立任务评价判断训练取舍。

前置知识：PyTorch 自动微分与计算图 · 损失、掩码与归约 · 微调与 LoRA · 训练诊断

本章学习目标

  • 把加权损失展开为共享参数上的梯度组合。
  • 用 autograd.grad 测量各任务的范数与夹角，处理未使用参数。
  • 依据独立任务指标和对照实验解释辅助目标的作用边界。

01损失权重最终作用于共享参数的梯度

共享参数是同时参与多个任务预测的参数，任务梯度是各损失对同一组参数的导数。加权目标将这些梯度线性组合，任务专属头则有各自坐标。先固定共享范围，再讨论协作或竞争。

多个任务可以共享一个表征网络，再接独立的分类或回归输出。总目标 L=La+λLbL=L_a+\lambda L_bL=La​+λLb​ 对共享参数 θ\thetaθ 的梯度为 ga+λgbg_a+\lambda g_bga​+λgb​⁠；任务专属头只接收与自己有关的梯度。任务相互促进或竞争主要需要在共享参数坐标上讨论，把两个独立头的不同坐标混进一个向量，会掩盖真正的交互位置。

配套网络让连续向量回归与四类状态分类共享一个主干。两项损失的数值和输出维数不同，但它们最终都通过同一组参数起作用。把两项梯度分别取出，再与加权总目标的梯度比较，可以直接看见这种叠加。

选择辅助任务应首先说明它与主任务的关系、标签是否可靠、部署时是否需要对应输出。增加一个能下降的 loss 并不自动产生有用表征；只有独立主任务和相关能力指标上的对照，才能回答辅助监督是否值得保留。

02loss 数值不能直接表示训练影响

损失值是目标在当前样本上的数值，训练影响则通过它对参数的导数和优化更新产生。常数偏置可以改变前者却不改变后者。因此比较任务影响，需要先统一参数坐标、单位与归约。

给某项 loss 加上不依赖参数的常数，不改变其梯度，却可以任意改变显示数值；改变目标单位、归约分母或输出维数，也会改变 loss 与梯度的尺度关系。因此把两项 loss 调到数字差不多，只是一种非常粗糙的观察，不能作为平衡任务影响的充分标准。

例：相同梯度可以对应不同 loss 数字

  1. 令 La(θ)=θ2L_a(\theta)=\theta^2La​(θ)=θ2⁠，Lb(θ)=θ2+1000L_b(\theta)=\theta^2+1000Lb​(θ)=θ2+1000⁠。
  2. 在 θ=1\theta=1θ=1 时，两项 loss 分别为 1 与 1001，梯度却都为 2。
  3. 若仅按 loss 数值把第二项缩小一千倍，就会人为降低一个本来同等强度的梯度。

数值大小与优化作用必须通过导数联系，不能直接等同。

先分别审查每项监督的单位、Mask、样本权重和归约。再在同一批次、同一参数状态上读取共享梯度范数，观察加权后的量 λ∥gb∥2\lambda\lVert g_b\rVert_2λ∥gb​∥2​ 相对于 ∥ga∥2\lVert g_a\rVert_2∥ga​∥2​ 的大小。梯度还可能集中在不同层，单个全局比值会遗漏局部变化；必要时按共享模块分组统计，但不应把大量日志本身当作结论。

调到相同 loss 数值就认为平衡

常数、单位与分母会改变数值解释。

检查：分别报告原始指标、有效数量及同一共享参数集合上的加权梯度范数。

03点积怎样描述局部任务关系

梯度点积衡量一个任务的局部下降方向怎样影响另一任务的一阶损失变化，余弦则只比较方向而忽略幅度。这个解释基于小步展开。下面先推导局部关系，再说明它不能推出什么。

若只沿任务 a 做小步 SGD，Δθ=−ηga\Delta\theta=-\eta g_aΔθ=−ηga​⁠，则任务 b 的一阶变化约为 −ηgb⊤ga-\eta g_b^\top g_a−ηgb⊤​ga​⁠。点积为正时，这一步在局部倾向于同时降低 b；为负时，b 可能上升。余弦将点积除以两者范数，保留方向关系而去掉绝对尺度。任一梯度为零时，它没有方向，余弦应记录为未定义而不是强行解释为正交。

这个推导只是一阶局部关系，依赖足够小的步长和当前样本。网络非线性、曲率、不同训练阶段与数据噪声都会改变后续行为。Adam 的预条件还会改变实际更新方向，因此原始梯度余弦不直接等于优化器一步的任务变化。需要时可直接计算真实 Δθ\Delta\thetaΔθ 与各任务梯度的点积，再对照实际 loss 差。

还可以比较每一任务在真实更新后的损失差与一阶预测 gi⊤Δθg_i^\top\Delta\thetagi⊤​Δθ⁠。两者相近时局部线性解释有参考价值；差异较大时可能因为步长、曲率或随机前向，不能再仅靠梯度夹角解释全部变化。这个对照也能发现记录的梯度是否来自更新前同一参数状态。

ΔLb≈−ηgb⊤ga,cos⁡(ga,gb)=ga⊤gb∥ga∥∥gb∥\Delta L_b\approx-\eta g_b^\top g_a,\qquad \cos(g_a,g_b)=\frac{g_a^\top g_b}{\lVert g_a\rVert\lVert g_b\rVert}ΔLb​≈−ηgb⊤​ga​,cos(ga​,gb​)=∥ga​∥∥gb​∥ga⊤​gb​​

余弦看方向，范数和权重看强度

只有余弦无法判断合成后谁占主导，也无法区分几乎为零的梯度。

检查：同时记录两个范数、加权范数比、点积和零范数状态。

04负余弦不等于辅助任务一定有害

梯度冲突通常指任务梯度在共享坐标中点积为负；合成更新则还包含权重与其他任务贡献。冲突不必然使主任务损失上升，更不直接判定辅助任务长期有害。下面区分这几层结论。

总梯度 g=ga+λgbg=g_a+\lambda g_bg=ga​+λgb​ 对主任务的一阶作用由 −ηga⊤g-\eta g_a^\top g−ηga⊤​g 决定。即便 gag_aga​ 与 gbg_bgb​ 反向，只要主任务项占优势，合成更新仍可降低主任务；权重过大才可能把方向推向相反。局部冲突也可能伴随更好的长期表示或正则作用，这需要固定预算的训练与验证，而不是从一次夹角直接推断。

例：完全反向时，权重决定是否抵消

  1. 取一维 ga=1g_a=1ga​=1⁠、gb=−2g_b=-2gb​=−2⁠，余弦为 -1。
  2. λ=0.25\lambda=0.25λ=0.25 时总梯度为 0.5，SGD 仍沿降低任务 a 的局部方向更新。
  3. λ=0.5\lambda=0.5λ=0.5 时总梯度为 0，λ=0.75\lambda=0.75λ=0.75 时总梯度为 -0.5，方向反转。

同一个负余弦对应降低、抵消或反转，必须一起看范数与权重。

反过来，正余弦也不能保证部署收益：两个任务可能共享同一个数据捷径，在训练集上共同下降，却在新场景失效。应跨批次和训练阶段采样统计，结合独立主任务指标、旧能力与任务分组表现。诊断的目的在于提出可验证假设，不是给某辅助目标贴上永久有益或有害的标签。

05用 autograd.grad 获取一致的共享坐标

逐任务梯度读取是在固定共享参数列表上，分别计算各损失导数的诊断操作。列表顺序定义同一向量坐标，未参与某任务的参数仍需保留其位置。下面据此组织可比较的梯度。

autograd.grad 返回对指定参数的导数，默认不写入 .grad，可用于诊断而不直接污染训练梯度。先固定共享参数列表顺序，对每项 loss 分别求导；未参与某任务的参数可返回 None，应在其原位置填同形状零，然后按相同顺序展平。删除 None 项会让两个向量的坐标不再对应，点积数值即使可计算也失去意义。

如果后面还要对总目标 backward，前面的诊断求导需要按需 retain_graph=True；通常只做一阶统计，不需要 create_graph=True。保留图和多次求导有额外时间与内存成本，适合定期抽样而非无条件每步用于整个大模型。若某 loss 本身完全不连接任何所选参数，还需明确处理其图状态，不要把 allow_unused 当成所有断图问题的自动修复。

余弦的数值实现还需避免中间溢出。即便各梯度坐标有限，直接平方、点积或范数乘积也可能超过 dtype 的范围；分别将两个向量除以各自最大绝对值，再计算单位方向的点积，数学上不改变余弦。零向量单独返回未定义；非有限梯度先拒绝，不能用 clamp 将 NaN 伪装成合法方向。对应练习保留大数反例以核验这一实现边界。

把 None 梯度删掉再拼接

两个任务将拥有不同的参数坐标排列，余弦可能没有数学意义。

检查：固定参数 ID 顺序，用同形状零占位；随后用总 loss.backward 验证组合梯度。

06多任务采样与权重共同定义训练期望

任务采样概率决定某目标被计算的频率，损失权重决定每次计算的梯度系数。它们共同定义长期训练期望。先写出两者的乘积作用，再判断均衡策略有没有重复加强某项任务。

如果每个 Batch 同时包含两个任务的标签，λ\lambdaλ 决定每个共同样本上两项损失的相对系数；如果交替抽取不同任务，任务抽样概率也会影响长期更新频率。把某任务采样概率提高两倍又将其权重提高两倍，可能产生重复加强。需要同时记录任务采样、标签可用率和有效元素归约，而不是只保存一个 λ\lambdaλ⁠。

缺失标签应通过各任务自己的有效位处理，不能把缺失类别当成负类、把缺失回归值当成零。每项分母要对应自己的目标；没有标签的分支可以不贡献监督，但共享主干仍可能被其他任务更新。看辅助分支验证误差时，也要区分它自身标签覆盖的变化与共享表征的真实变化。

当两个任务标签来自不同样本集合，梯度夹角还受抽到哪些条件影响。一个批次上看到竞争，可能是样本难度和类别构成造成的。可以在固定诊断集合上跨训练阶段重复测量，再与真实训练采样的统计比较，从而区分数据组成变化与参数状态变化。

07调整权重与进阶梯度方法的边界

任务平衡方法通过选择权重、采样或修改梯度来控制共享更新。它们改变优化过程，需要与单任务和固定权重基线比较。梯度几何提供线索，最终取舍仍由各任务的独立结果判断。

固定权重是可解释的起点。先验证单任务基线，再加入第二任务，用多个 λ\lambdaλ 在相同预算下比较主任务、辅助任务和需要保持的能力。权重太小可能几乎不起作用，太大可能主导共享表示；但最佳值不能只由初始一个 Batch 的梯度比确定，因为任务难度和梯度尺度会随训练改变。

GradNorm、梯度投影等进阶方法试图处理训练速度或局部冲突，但它们引入新的目标和超参数。它们不会修复数据泄漏、错误 Mask 或不相关标签，也不保证每项部署指标同时提高。阅读这些方法时先弄清实际修改的是损失系数还是梯度方向，再用可复查例子理解它与普通加权和的区别。

如果希望辅助任务只影响某些层，可以通过结构或梯度路径限定共享范围，但这也是模型设计变化。需要说明哪些参数接受哪些监督，保存完整参数组与消融结果，避免仅在论文或说明中声称“辅助监督”而代码实际更新了不同模块。

调整共享范围时，某个任务不再影响主干并不等于该任务不存在。它仍可能训练独立模块，但不能再用它的 loss 变化支持“共享表示得到改善”的结论。报告应列出每个目标连接的参数集合，让结构声明与实际梯度路径一致。

08从数学恒等式走向可审查实验

梯度分解恒等式可以证明代码符合目标，却不能单独证明辅助监督改善部署表现。把数学核验与独立实验分别设计，能够保留局部诊断的价值，同时避免从一张梯度曲线推断长期收益。

双任务网络的梯度验证分成两个对照：分别读取共享梯度，与总目标 backward 的结果逐元素核对 gtotal=ga+λgbg_{\mathrm{total}}=g_a+\lambda g_bgtotal​=ga​+λgb​⁠；再构造确定性相反目标，观察抵消。随机网络的余弦由实际计算决定，不预设必然冲突。未使用参数也保留同一坐标位置，诊断不写入 .grad，避免诊断过程本身改变后续训练。

实际实验应记录共同初始化、任务采样、训练步数、有效监督数量、梯度统计位置与独立指标。诊断时看到负余弦，提出一个具体假设，例如某阶段辅助任务过强，再通过调整权重或共享范围的单因素对照检验。不要只挑选支持假设的一个 Batch 或最好的一个种子。

最终验证关心的是需要保留的能力是否改善或至少满足约束，而不是某条余弦曲线是否看起来更漂亮。数学检查确保梯度实现符合定义，独立实验再回答这个定义是否适合任务；两种证据相互补充。

多任务梯度分析围绕同一共享参数展开：目标与采样决定合成梯度，局部几何解释短期作用，独立评价检验长期收益。损失大小、方向冲突和任务表现因此需要分开记录，再共同判断。
