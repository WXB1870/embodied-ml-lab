推导与分析

回归 loss 是 0.1，分类 loss 是 10，能否直接断言分类主导共享训练？

参考解与分析

不能。loss 数值受单位、常数项、分母和函数形状影响，而共享参数受到的是梯度。即使 loss 很小，也可能对某些参数产生较大梯度。

应固定共享参数范围，分别用 autograd.grad 读取范数与方向，再观察加权组合及各任务指标。示例只比较 trunk，避免把独立输出头的参数误当作共享干扰。

代码对应：演示 shared 的参数范围与 ga、gs；shared_gradient_report。

  • 能用给 loss 加常数的反例说明数值与梯度不同。
  • 能说明应该在哪组参数上比较任务作用。

发现两个任务梯度余弦为负，是否说明辅助任务一定有害？

参考解与分析

负点积说明在当前参数与数据上，单独沿一个任务的梯度下降方向，另一个任务的一阶变化可能上升。它不直接决定多步训练、预条件优化器和独立部署数据上的结果。

应汇总不同批次和阶段的统计，并用固定预算比较权重设置。二维抵消案例证明竞争可能发生，但不能把人工构造推广为所有辅助任务的效果；零范数时必须先标记方向未定义。

代码对应：演示 STEP 3 的确定性抵消；练习 cosine 的 None 分支。

  • 能用点积解释局部一阶竞争。
  • 能列出单批次夹角无法保证的外部效果。
  • 能正确处理零梯度夹角。

手算梯度合成与余弦

实现 gradient_relation(g_a, g_b, weight)，返回 (combined, cosine)。两个输入为等长非空有限数列表，weight 为有限非负数；combined = g_a + weight*g_b。cosine 比较两个原始梯度，任一个范数为零时返回 None。非法输入抛 ValueError。 合成梯度溢出时抛 ValueError；余弦应避免直接相乘大数范数造成的中间溢出。

提示
  • 合成梯度包含 weight；夹角比较的是两个原始梯度。
  • cosine 的分母为两个范数的乘积，零分母应返回 None。
参考实现与说明
参考实现
import math def gradient_relation(g_a, g_b, weight):    if not g_a or len(g_a) != len(g_b):        raise ValueError('向量形状不同')    if not math.isfinite(weight) or weight < 0 or any(not math.isfinite(v) for v in g_a + g_b):        raise ValueError('必须是有限数且权重非负')    combined = [a + weight * b for a, b in zip(g_a, g_b)]    if any(not math.isfinite(v) for v in combined):        raise ValueError('合成梯度超出浮点有限范围')    sa, sb = max(map(abs, g_a)), max(map(abs, g_b))    if sa == 0 or sb == 0:        return combined, None    # 两个正尺度分别约掉，不直接计算可能溢出的 dot 或 norm 乘积。    a, b = [v / sa for v in g_a], [v / sb for v in g_b]    na, nb = math.hypot(*a), math.hypot(*b)    cosine = math.fsum((u / na) * (v / nb) for u, v in zip(a, b))    return combined, max(-1.0, min(1.0, cosine))

余弦只比较方向，不包含梯度强度；相反方向是否完全抵消还取决于范数和权重。分别除以每个向量的最大绝对值，不改变它们的方向，再对尺度化向量求范数和点积，可避免有限坐标在直接平方或范数相乘时溢出。边界截断只修正正常舍入；非有限输入或合成结果必须先拒绝，不能把 NaN 截断成看似合法的余弦。

辨析与纠错

判断下面的说法或实现会在哪一步失效，并说明成立所需的条件，再展开分析核对。

辅助 loss 下降就认定主任务受益

共享表示可能偏向辅助任务或共同捷径。比较独立主任务、旧能力和部署指标，保留单任务基线。

只凭一次负夹角删除辅助任务

局部方向随样本和训练阶段变化，权重也影响合成方向。汇总跨批次统计并做固定预算对照。

用不同参数集合的梯度计算余弦

坐标不一致时结果没有可比意义。选择同一共享列表，None 保留零位置。

每步保留全模型图做梯度分析

可能显著增加内存与耗时并扰动训练。定期抽样、选定共享层，并在诊断后释放不需要的图。
