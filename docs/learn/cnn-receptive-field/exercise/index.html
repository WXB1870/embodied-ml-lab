推导与分析

先写出推导、计算或反例，再展开参考解核对假设与关键步骤。编程题位于下方，可从本页目录直接进入。

一个 RGB→64 的 3×3 卷积核包含多少输入通道？每个输出是否只依赖一种颜色？

参考解与分析

权重张量为 [64,3,3,3]。可以理解为 64 组滤波器，每组都包含覆盖三个输入颜色通道的 3×3 权重，普通 groups=1 卷积会把这些响应求和。

因此一个输出通道通常混合所有输入颜色；只有显式分组或 depthwise 设置才限制通道连接。输出通道数与核内部输入通道数是不同轴。

输入分辨率翻倍，为什么参数量不变，计算和显存却会增加？

参考解与分析

同一组核权重在所有空间位置共享，所以权重和偏置个数不变。输出高宽通常随输入增大，二维输出位置数可能约增为四倍，每个位置仍需一次局部内积。

训练还会保存更多中间特征和反向信息。应分别报告参数量、输出分辨率、激活规模及计算约定，不能用参数量单独估计运行成本。

两层 3×3 的第一层 stride=2，为什么第二层的感受野是 7 而不是 5？

参考解与分析

第一层覆盖跨度为 3，输出相邻格子在原输入上的间隔为 2。第二层再覆盖三个这样的格子，新增跨度为 (3−1)×2=4(3-1)\times2=4(3−1)×2=4⁠，所以总跨度为 7。

最终累计步长仍为 2。这个 7 是理论包围跨度；边界填充、空洞采样或特定输入下关闭的激活，会让真实参与或有效贡献与 7×7 不同。

CNN 是否对任意图像平移都保持相同预测？

参考解与分析

不是。理想 stride=1 卷积主要体现平移等变，即特征跟着移动；它并不直接意味着输出不变。有限边界和下采样还会限制理想等变关系。

分类读出可能通过池化获得一定位置鲁棒性，空间定位却要随物体移动改变预测。应先定义任务的几何要求，再测试平移、裁剪和标签同步。

Conv2d(kernel=P,stride=P) 为什么能替代一层 patch Linear，却不能替代完整 Transformer？

参考解与分析

不重叠窗口展平成 CinP2C_{\mathrm{in}}P^2Cin​P2 向量后，卷积在每个窗口复用同一权重，等价于一次共享 Linear，前提是通道与空间的展平顺序一致。

这种局部投影尚未混合不同 patch。Transformer 后续还有位置表示、Attention、前馈网络等计算，不能由这一层投影等价推导出整个架构等价。

坐标误差为零，是否能证明热图已正确锁定一个目标？

参考解与分析

不能。空间期望只约束分布的一个矩；中间单峰与对称双峰都可以有同样的均值。坐标正确不意味着概率集中在真实目标上。

并列峰在温度趋近零时仍可能共享概率，均值落在峰之间。可结合任务需要检查分布形状、局部监督或多目标假设，但不能从坐标 Loss 一个数推断热图正确。

为什么“depthwise 后接 1×1 卷积”并不等价于任意普通卷积？

参考解与分析

在两层之间没有非线性、depthwise 倍增系数 K=1K=1K=1 时，等效核 Wocuv=PocDcuvW_{ocuv}=P_{oc}D_{cuv}Wocuv​=Poc​Dcuv​⁠。固定 c，所有输出的空间核都成比例，因此这一 Cout×KhKwC_{\mathrm{out}}\times K_hK_wCout​×Kh​Kw​ 切片秩最多为 1。

若两个输出需要来自同一输入通道的线性独立空间核，如横向和纵向差分，这个结构不能精确表达。K 个独立 depthwise 核将秩上限提高到 K；加入非线性后则不再能用一个固定等效核比较。

stride=2 是否必然丢失信息？抗混叠是否能同时保证所有细节和任意平移不变？

参考解与分析

不必然。用四个输出通道分别存储每个 2×2 patch 的四个像素，就是可逆的空间到通道重排。一般线性 patch 投影是否单射取决于输入输出维数与矩阵秩。

同一通道直接降采样会把某些频率混叠。低通滤波能降低混叠，但通过削弱高频实现，不能同时承诺原样保留全部细节。有限边界、后续非线性与新一轮采样还会影响平移响应。

两个特征图形状、累计 stride 和感受野都相同，是否可以直接逐位置融合？

参考解与分析

还需要检查采样原点与中心偏移。不对称 padding 的左右分配不同，可以保持输出个数、r 和 j 相同，却使 a 不同。逐元素加法在张量维度上合法，不代表对应位置观察同一原图区域。

为每条分支按相同像素坐标约定记录 r、j、a，并结合 resize、crop 等预处理变换核对。边界补值与真实图像支持不同，理论中心也不等于实际贡献质心。

参考实现
def conv_geometry(size, layers):    if size <= 0:        raise ValueError("输入尺寸必须为正")    receptive, jump = 1, 1    for kernel, stride, padding, dilation in layers:        if min(kernel, stride, dilation) <= 0 or padding < 0:            raise ValueError("卷积参数无效")        size = (size + 2*padding - dilation*(kernel-1) - 1)//stride + 1        if size <= 0:            raise ValueError("没有有效输出位置")        receptive += (kernel-1)*dilation*jump        jump *= stride    return size, receptive, jump

步长会改变下一层窗口在原输入上的跨度，所以感受野不能简单相加核尺寸。Padding 影响输出位置，不增加中央输出的理论核跨度。

辨析与纠错

判断下面的说法或实现会在哪一步失效，并说明成立所需的条件，再展开分析核对。

只在单通道方阵上验证卷积

通道求和、核转置和高宽混淆可能被对称样例掩盖。

采用非方形输入/核、多输入输出通道和非对称值，与官方实现比较数值及梯度。

把 dilation 当成增加核权重数

dilation 扩大采样间隔，不直接增加核中的权重数。

分别记录核点数 KhKwK_hK_wKh​Kw​ 与有效跨度 d(k−1)+1d(k-1)+1d(k−1)+1⁠。

分组后仍然混合所有输入通道

groups 限制的是连接结构，错误 reshape 可能导致组间串线。

按同一组顺序拆分输入窗口与权重，测试 depthwise 特例。

将全局池化用于任何空间任务

汇总后可能无法区分需要不同坐标输出的空间排列。

对比空间 token、热图或显式位置读出，并检验不同场景是否被汇成相同表示。

冻结参数却忽略 BatchNorm 运行统计

训练模式下 running_mean/variance 仍可能变化，导致冻结编码器实际行为改变。

分别核对参数梯度、train/eval 模式、缓冲区和预处理配置。

把恢复图像尺寸当成恢复原图

ConvTranspose 或上采样得到相同 H/W，并不保证逆转下采样和信息丢失。

区分几何尺寸与信息可逆性，用已知输入和任务相关指标验证重建或定位。
