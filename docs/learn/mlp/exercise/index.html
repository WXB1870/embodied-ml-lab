推导与分析

先写出推导、计算或反例，再展开参考解核对假设与关键步骤。编程题位于下方，可从本页目录直接进入。

线性层可以合并，为什么把一个 Linear 拆成两个后，训练结果仍可能不同？

参考解与分析

合并关系只说明有效矩阵 W=W2W1W=W_2W_1W=W2​W1​ 表示同一个函数；对 W1W_1W1​⁠、W2W_2W2​ 求梯度时，分别还要乘另一个矩阵，所以直接更新 W 与更新两个因子后再相乘，不是同一个参数更新。瓶颈还可能限制 W 的秩。

标量 y=aby=aby=ab 的反例尤其清楚：(1,1) 与 (100,0.01) 都给出 1，但平方损失的梯度是 (1,1) 与 (0.01,100)。同一学习率下，一组小幅改动输出，另一组可能越过目标并增大损失。

因此“可合并”不能推出相同的优化速度、正则化效果或数值稳定性。判断增加深度是否有价值，需要分别讨论函数约束、参数化和所用优化器。

把 [B,T,D] 输入 Linear(D,H)，为什么不会在时间维交换信息？

参考解与分析

Linear 在每个前导位置应用同一组 D→H 权重，计算 y[b,t] 时只使用该位置的输入向量。T 是批量位置而非被求和的特征轴。

如果该 token 已经过 Attention，它可能含上下文，但这来自上游。想让原始 token 在当前模块里交互，需要显式混合 T 轴、卷积、Attention 或声明的汇聚操作。

同一批样本为什么得到两组不同形状的偏置梯度？损失值是否可以直接当作梯度？

参考解与分析

损失是标量 0.092791666…0.092791666\ldots0.092791666…⁠，对预测的导数却是六个元素组成的 G=(Y^−Y)/6G=(\widehat Y-Y)/6G=(Y−Y)/6⁠。第二层偏置被三条样本共享，所以其梯度是 G 沿 Batch 求和，得到 [0.101666…,−0.096666…][0.101666\ldots,-0.096666\ldots][0.101666…,−0.096666…]⁠。

第一层偏置还要经过 W₂ 与 ReLU 导数，先计算 Δ1=(GW2)⊙1{Z>0}\Delta_1=(GW_2)\odot\mathbf1\{Z>0\}Δ1​=(GW2​)⊙1{Z>0}⁠，再沿 Batch 求和，得到三维梯度 [0.0415,−0.028666…,0.038166…][0.0415,-0.028666\ldots,0.038166\ldots][0.0415,−0.028666…,0.038166…]⁠。这与每层偏置自身的形状一致，不能由 loss 的数值或输出形状猜测。

目标标准化为何不能只当成“不改变问题的数值技巧”？

参考解与分析

标准化后的平方误差等于原误差除以各维标准差的平方，改变了不同输出维度在总损失中的相对权重。若这是有意的平衡方式，应明确记录。

还要只用训练集拟合统计量、保存尺度并在推理中逆变换。评价真实误差时回到原单位，避免用标准化后的数值直接解释物理精度。

这也有成立边界：不受函数族约束时，每维固定正权重不会改变其最优条件均值；共享参数和有限容量会让各维发生取舍。不能把“损失度量改变”与“所有情形下统计最优值都改变”混为一谈。

小批次能拟合，是否已经证明这个读出头可用于真实机器人？

参考解与分析

只能说明固定样本上的输入、目标和优化链路至少能够让该网络降低损失。它不覆盖分布外观测、闭环误差积累、时间同步或控制约束。

接下来要使用按轨迹/任务等合理粒度划分的独立数据，核验预处理与动作逆变换，再做与任务相符的闭环评估。训练指标和执行指标应分别报告。

先 MLP 后平均，与先平均后 MLP，有哪些差异？

参考解与分析

先平均后 MLP 只依赖原始均值。任何两个均值相同的输入集合，对任意确定性下游网络都会给出相同结果；这是一条由输入决定的不可区分性，不是网络不够宽。

先逐 token 非线性映射再平均，可以统计新的特征。例如 {−1,1}\{-1,1\}{−1,1} 和 {0,0}\{0,0\}{0,0} 均值相同，平均 ReLU 却为 0.5 和 0。训练能改变保留哪种统计量，但共享逐 token MLP 加平均仍对共同重排不变。

平均嵌入也不区分一个集合和它的完整重复。若目标需要顺序、位置或数量，必须检查这些信息是否已经被上游写入特征，或通过读出结构显式保留；改变隐藏层宽度不能恢复已经丢掉的信息。

已经构造出任意精细的 ReLU 插值，为什么还不能说增加宽度一定改善真实任务？

参考解与分析

构造证明的是给定节点值后存在一组参数，并在一维 C2C^2C2 函数、指定紧区间和最大误差度量下给出精确界。它没有研究训练算法、带噪采样和分布外输入。

更宽的网络可以包含更好的候选函数，但优化器未必找到它，有限数据也未必足以辨认它。应分别评估表示限制、训练误差、独立验证以及输入信息是否充分。

参考实现
def mlp_forward(x, w1, b1, w2, b2):    hidden = [max(0., sum(w * xi for w, xi in zip(row, x)) + bias)              for row, bias in zip(w1, b1)]    return [sum(w * hi for w, hi in zip(row, hidden)) + bias            for row, bias in zip(w2, b2)]

最后一个测试检查输出允许负值。一般实数回归在没有额外范围约定时，不应在最后加 ReLU；隐藏层仍需要非线性。

辨析与纠错

判断下面的说法或实现会在哪一步失效，并说明成立所需的条件，再展开分析核对。

把 Linear 权重按 [in,out] 使用

形状恰好为方阵时，错误转置可能不会报错。

用非方形权重和手算输入，与 F.linear 输出对照。

回归目标广播成跨样本矩阵

[B,1] 减 [B] 可广播到 [B,B]，损失仍能正常返回标量。

损失前断言预测与目标完全同形。

两次归一化分类输出

先 Softmax 再 CrossEntropy 会把概率当作 logits，改变优化目标。

分类头输出原始 logits，概率仅在需要展示或采样时计算。

无效 token 先乘零再池化

NaN×0 仍为 NaN，且固定除以 T 会受 Padding 数影响。

先替换无效值，逐样本除以有效数，并处理全无效行。

标准化统计与模型分离

推理使用另一套均值、遗漏尺度或逆变换，会改变输入与输出语义。

统计量写入 buffer 或有版本的处理器，并做保存恢复对照。

看到 grad 就认为参数在学习

优化器可能漏掉参数、学习率可能为零，或更新量远小于数值分辨率。

比较参数身份、梯度范数和 optimizer.step 前后的真实位移。
