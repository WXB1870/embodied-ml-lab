多层感知机（MLP）是一种将全连接仿射层与非线性激活交替组合的神经网络，也就是由可学习参数组织的多层函数模型。仿射层混合输入特征，激活使组合能够表达非线性关系，损失与反向传播再让参数从数据中学习。本章沿同一个 2→3→2 网络认识各组成部分，完成前向、损失、五组梯度与一次更新，再讨论表达能力和训练条件。

前置知识：张量与广播 · 线性代数与矩阵求导

本章学习目标

  • 说明仿射变换与激活如何共同表示非线性函数
  • 计算网络的输出形状、参数量与共享计算范围
  • 分别实现一般向量回归和序列分类，匹配输出与损失约定

01从仿射变换到非线性函数

仿射层用权重混合输入并加偏置，激活函数对所得响应作非线性变换。将两者交替组合才构成这里讨论的 MLP；只有仿射层的堆叠仍然是一个仿射映射。先认识这两个单元，再追踪完整网络。

一个全连接层为每个输出特征学习一组输入权重，再加一个偏置。输入不是必须为图像或文本；关节状态、图像 token、融合后的场景表示都可以作为向量。权重决定输入方向如何混合，偏置让输出在输入为零时也能有非零值。带偏置的操作严格说是仿射变换。PyTorch 的 Linear 沿最后一个维度计算，其余维度作为批量位置保留。

如果把多个 Linear 直接串联，中间没有非线性，它们仍能合并成一个仿射变换。两层的合并权重是两个权重矩阵的乘积，偏置也能相应合并。深度此时改变了参数化和可能的秩约束，却没有得到任意弯曲的函数。激活函数让不同输入进入不同的计算区域。例如 ReLU 对负预激活输出零，整个网络成为连续的分段仿射函数。

以标量输入为例，两个带偏置线性层满足 w2(w1x+b1)+b2=(w2w1)x+(w2b1+b2)w_2(w_1x+b_1)+b_2=(w_2w_1)x+(w_2b_1+b_2)w2​(w1​x+b1​)+b2​=(w2​w1​)x+(w2​b1​+b2​)⁠，斜率在整个输入轴上相同。若中间插入 ReLU，w2max⁡(0,w1x+b1)+b2w_2\max(0,w_1x+b_1)+b_2w2​max(0,w1​x+b1​)+b2​ 会在预激活过零处改变斜率。多个隐藏单元可以在不同位置改变斜率，非线性表达由此逐步形成；后面的显式插值构造将把这一观察变成可检验的函数表示。

02张量形状、参数朝向与参数量

网络形状约定说明每个数组承载输入、隐藏表示、输出还是参数，以及各轴怎样对应。参数量则计数独立可学习的数值，不随同一权重被多少样本复用而增加。下面固定同一个 2→3→2 模型，为全部手算建立坐标。

采用行向量组成 Batch 的约定：输入 X 为 [B,D]，第一层权重 W1W_1W1​ 为 [H,D]，偏置为 [H]，所以 X@W1.T 得到 [B,H]。第二层权重为 [O,H]，输出为 [B,O]。不要凭矩阵名判断乘法方向，应从相邻内维是否相等，以及每个轴代表什么来核对。nn.Linear(D,H).weight 的第一维是输出数，这与某些教材把权重写成 [D,H] 的约定相反。

例：从同一个 2→3→2 网络数出 17 个参数

  1. 输入 X:[B,2]。第一层 Linear(2,3) 的权重为 [3,2]、偏置为 [3]，输出为 [B,3]，参数数为 3×2+3=93\times2+3=93×2+3=9⁠。
  2. ReLU 不增加参数，第二层 Linear(3,2) 的权重为 [2,3]、偏置为 [2]，输出为 [B,2]，参数数为 2×3+2=82\times3+2=82×3+2=8⁠。
  3. 总数为 9+8=179+8=179+8=17⁠。后面的三条输入使用同一组参数；把 Batch 从 3 改成 30，不会把 17 变成 170，只会改变激活与计算量。

贯穿案例的前向、反向与一次更新使用这 17 个可训练数。先逐层计数，再推广到一般 D→H→O 公式；补充形状片段会单独注明所用尺寸。

两层有偏置的 D→H→OD\to H\to OD→H→O 网络，参数量是 DH+H+HO+ODH+H+HO+ODH+H+HO+O⁠。Batch 大小不进入参数量，因为不同样本共享同一组权重。Batch 和序列长度会改变计算量及中间激活大小。若把 100 个 token 展平成一个大向量再接全连接，输入维度会从 D 变成 100D，参数量及结构假设都会变化。

输入也可以是 [B,T,D]。Linear(D,H) 会在每个 b,t 位置复用同一个映射，输出 [B,T,H]，不会自动让两个时间步互相通信。把前两个轴临时合为 BTBTBT 后计算，再恢复形状，与保留三维输入等价；把 T 和 D 合并则是另一种模型。维度重排需用 transpose/permute，reshape 只改变元素如何分组，不能替代轴交换。

参数量与训练内存不是一回事。参数需要存储权重，优化器还可能维护一阶、二阶状态；训练反向需要保留中间激活。把序列长度翻倍不增加共享 Linear 的权重，却通常增加激活占用与矩阵乘法工作量。估算时分别列出参数、梯度、优化器状态和激活，并注明 dtype，不能只用一个参数量乘常数覆盖所有训练设置。

05ReLU、GELU、SiLU 与饱和

激活函数是隐藏层中的逐元素非线性变换，既决定前向响应，也决定反向的局部斜率。ReLU 用分段截断，GELU 与 SiLU 用平滑调制，饱和则表示局部变化趋小。下面在同一个小网络中观察这些性质。

ReLU⁡(x)=max⁡(0,x)\operatorname{ReLU}(x)=\max(0,x)ReLU(x)=max(0,x)⁠，在正半轴导数为 1，在负半轴导数为零。PyTorch 在零点采用零导数。某条样本的一个激活为零是正常稀疏性；一个神经元对几乎所有训练样本都落在负区间，且长期无法更新，才值得怀疑为失活。过大的学习率、偏置变化和输入尺度都可能改变激活分布，因此排查应统计一批数据及多个训练步骤。

GELU 用 xΦ(x) 平滑调制输入，SiLU 使用 x·sigmoid(x)。它们不像 ReLU 那样把整个负半轴精确截成零，但也不意味着梯度永远足够大或训练一定更好。Sigmoid 与 tanh 在输入绝对值很大时会饱和，导数接近零；这在输出范围约束中可能有意义，在深层隐藏网络里则需要关注尺度。不同激活的值域和导数会影响初始化与优化，不能只把名称换掉。

在一个不跨越 ReLU 零点的局部区域，激活开关可以写成对角矩阵 D(x)D(x)D(x)⁠，按列向量约定，输入 Jacobian 为 W2D(x)W1W_2D(x)W_1W2​D(x)W1​⁠，其秩受输入维度、输出维度和有效隐藏单元数共同限制。输入跨过边界时 D(x)D(x)D(x) 改变，网络换成另一段仿射映射。局部低秩与全局只能线性表达不是一回事；非线性能力来自这些区域的组合。

输出层通常由目标语义决定。实数回归常使用线性输出；分类输出 logits，概率变换交给稳定的损失函数；若动作确实受已声明的固定上下界约束，可以使用缩放后的 tanh，但接近边界时梯度会变小。对所有输出使用 ReLU 会禁止负数预测，在最后一层使用 Softmax 会引入各维和为一的约束，这些都改变了问题定义。

在贯穿例中，第一条样本的第二个隐藏单元关闭，而其他样本仍能更新它。可在 manual-backprop 中只修改 b1[1]，重新记录 z 的符号和 Δ₁；统计初始化对批量开关分布的影响见激活与初始化。原有手写梯度练习仍使用不同尺寸测试，检验是否理解一般链式法则，而非仅记住这组数字。

07初始化与优化几何

初始化为网络选择训练起点，标准化改变输入或目标的数值坐标。两者都影响信号与梯度的尺度，但分别作用于参数和数据。下面在已经明确的前反向计算上分析它们，而不把尺度规则当作收敛保证。

初始化需要避免信号经过多层后迅速放大或缩小。Xavier 根据输入与输出连接数设置尺度，Kaiming 常用于 ReLU 类网络，根据激活和 fan_in/fan_out 选择增益。这些推导依赖关于输入、权重和独立性的统计近似，不保证任意网络都稳定。nn.Linear 的默认初始化不能简单等同于手工设置 nonlinearity="relu" 的 Kaiming 初始化；若需要后一种，应显式配置并检查权重朝向。

08回归、单标签分类与多标签分类

回归预测连续量，单标签分类从互斥类别中选一个，多标签分类则分别判断多个标签是否成立。这些任务可以使用相似的 MLP，却要求不同输出含义与损失。先定义要预测什么，再确定激活、标签形状与归约。

MSE 适合用平方误差定义的连续目标，默认 mean 会对所有元素取平均；[B,O] 的分母因此为 BO。若 O 个维度代表不同单位，或只有部分动作维度有效，需要显式定义权重、Mask 和分母。L1、Huber 等目标对误差的惩罚方式不同，不能仅因数值更小就判断模型更好。把可见性为假的目标填零后直接当真实零监督，会把缺失信息写进学习目标。

互斥的 C 类分类通常输出 [B,C] logits，CrossEntropyLoss 接收未归一化 logits 与类别索引，内部完成稳定的 LogSoftmax 与负对数似然计算。先手动 Softmax 再传入，会让 API 把概率误当作新的 logits。二分类或多个可以同时成立的标签可使用 BCEWithLogitsLoss，目标与 logits 形状一致；多标签不要求各标签概率和为一。类别索引和概率目标的含义也需要区分。

序列分类输出 [B,T,C] 时，可以将 logits 展成 [B×T,C]、标签展成 [B×T]，并用有效位筛选；或按所用 API 把类别维放到指定位置。仅凭 shape 能广播不代表监督正确。例如 [B,1] 的预测减去 [B] 目标会得到 [B,B]，把不同样本互相比较。应在损失前断言预测和回归目标形状相同，并对全无效 Batch 制定明确策略。

对具有有限二阶矩的连续目标，平方误差的最优确定性预测是给定输入后的条件均值。若同一观测下存在两个相距很远的可行动作，均值未必仍是可行动作。此时增加 MLP 宽度不能消除确定性均值目标的局限，需要检查条件信息是否不足，或考虑分布式、混合分量、扩散或流匹配等生成目标。单峰监督的小回归例子不能代表这类多模态问题。 固定的逐维正权重不会改变不受限制预测函数的每维最优条件均值；有限容量和共享参数下的取舍则会改变。若权重还依赖标签，最优值一般变成 E[wY∣x]/E[w∣x]\mathbb E[wY\mid x]/\mathbb E[w\mid x]E[wY∣x]/E[w∣x]⁠，需要重新解释学到的统计量。

09把小网络训练成一个可检查的实验

训练循环是在同一组参数上反复执行取样、前向、计算损失、反向和更新的过程。它把已经手算过的一次变化变成从数据学习的算法。下面用小数据核对各步顺序与实际参数变化。

一个训练步骤至少包含读取正确的 Batch、前向、按声明的归约计算损失、清除旧梯度、反向和更新。zero_grad 放在 backward 前，optimizer.step 放在 backward 后。训练多个微批次时则有意识地累积梯度，不能一边累积一边清空。参数必须既注册在 Module 中又被优化器管理；需要更新的张量被 detach，或在创建优化器后才新加模块，都可能出现损失有值却没有预期学习的情况。 具体而言，普通 Python 列表不会像 ModuleList 那样注册子模块；在 forward 中每次新建 Linear 会不断生成新参数。检查 named_parameters 和 step 前后的参数位移，可区分结构存在、梯度存在与实际更新这三个条件。

调试时先固定一小批数据，关闭不必要的随机增强，检查网络能否降低这批数据的损失。同时记录输入/目标范围、预测均值、各层梯度范数和参数更新幅度。训练损失下降只说明这条固定优化链路在工作；验证泛化需要独立数据划分、正确 eval 模式及任务指标。不能用“成功记住一个 Batch”替代性能评估，也不应在完全无法拟合少量干净样本时先堆复杂正则化。

train()/eval() 控制 Dropout、BatchNorm 等模块行为，no_grad() 控制是否记录求导图，它们解决不同问题。推理通常同时 eval 与 no_grad；训练冻结骨干时，如果骨干前面还有需要学习的输入适配器，不能把整个骨干前向无条件放进 no_grad。第二个完整演示保存了输入/输出统计缓冲区，展示从原始单位到标准化训练再回到原始单位的完整过程，并分别报告训练和留出损失。

10非线性与池化的顺序

读出是把网络内部表示变成最终预测的操作，池化是其中汇总多个位置的一种方式。逐位置 MLP 本身不交换 Token 信息，因此非线性在汇总前后的位置会改变保留的信息。先定义读出，再比较其顺序。

对 [B,T,D] 逐 token 应用同一个 MLP，不会在该 MLP 内交换 token 信息。若输入来自已经混合上下文的 Transformer，单个 token 可能含有全局信息，但那是上游网络的结果。要把 T 个 token 变成一个预测，需声明读出方式：选定汇聚 token、有效平均池化、固定顺序拼接，或用查询注意力读出。这些方式的假设和计算开销不同，不是等价的 shape 操作。

有效平均池化需要在特征维广播 [B,T] 的 Mask，分母是每条样本的有效 token 数。Padding 值可能不为零；甚至可能包含非有限占位值，因此先用 masked_fill 或 where 替换无效位置更稳妥，单纯乘零不能消除 NaN。全无效样本应拒绝或使用明确定义的缺失分支。把整批有效数作为每条样本的分母，会错误地让样本之间互相影响。

平均池化对输入 token 的共同重排不变。若上游特征没有编码必要的空间、相机或时间信息，两个不同场景可能得到同一均值，之后再大的 MLP 也无法区分。位置编码可能在特征中保留一部分信息，但均值映射仍不是一般可逆的。具身模型可把本体状态或任务条件与视觉表示拼接后读出，也可使用更结构化的 token；选择应通过信息保留、监督一致性和受控消融来判断。

11容量、泛化与故障定位的顺序

容量限制、优化失败和泛化不足分别指函数族不够、参数没有学到合适解、以及学得结果无法适用于目标数据。它们可能产生相似误差。下面按输入、计算图、更新和数据分布逐项区分。

训练损失高时，优先检查目标是否可预测、样本与标签是否对齐、数值范围是否合理、损失分母是否正确，以及参数是否真的更新。检查 grad=None 与数值为零的梯度有助于区分没有参与计算和导数为零，但要结合计算图：并非所有参数都应在每条分支中出现。梯度存在也不代表更新有效，还要看优化器参数列表、学习率、裁剪和精度缩放。

若小批数据可以拟合，而独立验证集表现差，才继续分析数据覆盖、模型容量、正则化和划分方式。训练/验证来自同一条轨迹的相邻帧可能让结果过于乐观；验证集上反复调参也会影响独立性。增加隐藏宽度能提高某些函数的拟合能力，但可能加剧记忆噪声。Dropout、权重衰减和早停各有作用，不能取代检查标签与输入的因果关系。

线性读出与非线性 MLP 读出的比较可以帮助判断表示的可用程度，但它不是对“信息是否存在”的绝对检验：有限数据、优化难度和评价指标都会影响结果。头部训练成功不等于冻结骨干学到了新能力；同样，训练失败也不直接证明骨干完全没有信息。报告实验时应说明骨干是否冻结、读出头结构、输入池化、目标标准化、数据划分，以及实际评价的量。

读出实验还应防止使用未来信息。例如预测当前动作时，输入特征若由整段轨迹包含未来帧的编码器生成，离线拟合可以很好，实际执行却无法获得相同条件。检查特征缓存时应保存其模型版本、处理方式和时间范围，核对训练所需的信息在推理时确实可用。这样的输入可用性检查与选择网络宽度同样重要。

一个 MLP 的完整计算由仿射层、非线性、读出和损失构成，训练再沿同一依赖回传梯度并更新参数。能解释这条链以后，表达能力、初始化和泛化就成为对同一个模型不同层面的分析。
