本章贯穿案例

二维条件多峰 Flow Matching：训练、速度场与误差分解

在每个条件下学习两个高斯模式。代码使用解析混合边际场作为 oracle，并分别度量学习场误差、数值积分误差与有限样本分布差异；默认在 CPU 训练并输出 fm_mixture_results.json。

运行时应核对

输出独立探针误差、细网格复核和 Euler/Heun 不同 NFE 的指标，并写出可绘图的 JSON。固定种子在本次 CPU 运行中目标 MSE 为 2.4931→1.2641；不同环境浮点结果可略有差异。检查只要求明确的公式、有限性、确定性及本合成训练改进，不把这些数值作为真实策略性能。

完整实现 A：条件高斯上的速度回归与 Euler 采样

从随机端点训练一个小 MLP，再从新噪声生成二维样本。给出同一合成分布的解析边际速度，展示为什么正确 MSE 也未必为零。全程 CPU，不依赖额外 Flow Matching 库。

运行时应核对

固定种子下，独立探针 MSE 应低于训练前；各条件的采样均值靠近各自高斯簇。解析边际场的样本级 MSE 仍非零。256 步 Euler 与解析终点的最大误差小于 0.04。该例只验证合成单高斯条件分布，不证明真实动作泛化或多峰覆盖。

import mathimport torch torch.manual_seed(52)torch.set_num_threads(1) # 1. 对有效标量元素求均值；先安全选择，再相减与平方。def masked_mse(prediction, target, valid):    if prediction.shape != target.shape or valid.dtype != torch.bool:        raise ValueError("prediction/target 同形，valid 必须为布尔张量")    valid = torch.broadcast_to(valid, prediction.shape)    count = valid.sum()    if count.item() == 0:        raise ValueError("没有有效监督")    safe_pred = torch.where(valid, prediction, torch.zeros_like(prediction))    safe_target = torch.where(valid, target, torch.zeros_like(target))    if not torch.isfinite(safe_pred).all() or not torch.isfinite(safe_target).all():        raise ValueError("有效元素必须有限")    return (safe_pred-safe_target).square().sum() / count #
