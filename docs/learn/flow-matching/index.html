01先确定要生成什么：从高斯噪声到二维双峰

速度场是一个根据当前位置、时间与条件给出瞬时移动方向和速率的函数。许多噪声起点沿它运动，终点集合才构成生成分布。我们先明确要生成的双峰分布，再解释怎样从已有数据为这个函数建立监督。

Flow Matching（FM）是一种训练连续生成模型的方法：给出连接噪声与数据的概率路径，让神经网络回归推动这条路径的速度。固定条件 ccc⁠，从 X0∼N(0,I2)X_0\sim\mathcal N(0,I_2)X0​∼N(0,I2​) 出发，求解 dXt/dt=vθ(Xt,t,c)dX_t/dt=v_\theta(X_t,t,c)dXt​/dt=vθ​(Xt​,t,c)⁠，到 t=1t=1t=1 得到二维样本。一个起点产生一条轨迹，许多起点的终点共同定义生成分布；网络需要学的是随状态和时间变化的函数，而非一条固定方向。

FM 不限定网络架构；本章使用小型 MLP。Continuous Normalizing Flow（CNF）描述用连续 ODE 流变换分布的模型，FM 则给出训练这种流的一类目标。只有要计算密度时，才另需处理散度与密度演化。核心路径回归不以前向 SDE 或 Score 为先修；它们与本方法的联系在末尾的比较节展开。

线性条件路径是在固定噪声与数据端点之间进行插值的样本路径。路径在每个时间的位置和导数都可直接算出，因此为速度回归提供训练输入与标签。下面沿同一对二维端点先完成这一步。

03从条件速度回归到边际速度

本章的条件速度是固定训练端点路径的时间导数；边际速度是在给定中间状态、时间与观测条件后，对可能端点速度求条件平均。网络只看到后面这些可用信息。平方回归为何以这个平均为最优解，是本节要证明的关系。

沿用线性路径，先抽 (X1,c)∼pdata(X_1,c)\sim p_{\rm data}(X1​,c)∼pdata​⁠，独立抽 X0∼p0X_0\sim p_0X0​∼p0​ 与 t∼Uniform⁡(0,1)t\sim\operatorname{Uniform}(0,1)t∼Uniform(0,1)⁠，再构造 Xt=(1−t)X0+tX1X_t=(1-t)X_0+tX_1Xt​=(1−t)X0​+tX1​ 和 U=X1−X0U=X_1-X_0U=X1​−X0​⁠。训练目标完整写为 LCFM(θ)=Et,X0,X1,c ⁣[∥vθ((1−t)X0+tX1,t,c)−(X1−X0)∥2].\mathcal L_{\rm CFM}(\theta)=\mathbb E_{t,X_0,X_1,c}\!\left[\left\|v_\theta((1-t)X_0+tX_1,t,c)-(X_1-X_0)\right\|^2\right].LCFM​(θ)=Et,X0​,X1​,c​[∥vθ​((1−t)X0​+tX1​,t,c)−(X1​−X0​)∥2].网络读取中间状态、时间和条件，端点只用于训练时产生监督。

持续重采样的训练损失不必趋近零；只凭它不为零，不能断言优化失败。

进一步把 vθ−Uv_\theta-Uvθ​−U 写成 (vθ−m)−(U−m)(v_\theta-m)-(U-m)(vθ​−m)−(U−m)⁠。交叉项的期望为 E[(vθ−m)⋅E[U−m∣Z]]=0\mathbb E[(v_\theta-m)\cdot\mathbb E[U-m\mid Z]]=0E[(vθ​−m)⋅E[U−m∣Z]]=0⁠，得到下面的正交分解：CFM 损失等于模型到边际场的平方误差，再加上输入无法解释的条件方差。等式按固定采样分布几乎处处理解。它不仅给出最优解，还解释了训练损失为什么可能在模型正确时仍非零。

“相同梯度”说的是总体损失的期望梯度。数据、噪声、端点耦合与时间采样分布在这个论证中都固定，不依赖正在优化的 θ\thetaθ⁠；条件方差项才是常数。网络内部可以训练条件编码器，但 ZZZ 中的 ccc 应理解为固定原始条件，而不是把随 θ\thetaθ 改变的中间特征当成固定随机变量。若联合采样机制也学习或重加权，需要重新检查求导项。

单个 UUU 的梯度依然有噪声，并不逐样本等于回归 mmm 的梯度。因此随机重采训练中存在非零最优 MSE，减少该值也不直接等同于减少采样误差。对给定位置的速度进行平均时，权重来自经过这里的配对后验，不能把所有端点配对的速度等权平均。

加权时也有边界。若非负权重 λ\lambdaλ 只依赖 ZZZ 且不依赖 θ\thetaθ⁠，同一个条件均值仍是每个正权重位置的最优解。若 λ\lambdaλ 还依赖模型没看到的端点或目标，最优解改为 E[λU∣Z]E[λ∣Z]\frac{\mathbb E[\lambda U\mid Z]}{\mathbb E[\lambda\mid Z]}E[λ∣Z]E[λU∣Z]​⁠，分母须为正；这一般不是原来的边际速度。按困难样本或端点收益加权，会重新定义回归问题，不能不经推导就继承原来的运输结论。

条件直线可以相交，实际 ODE 流则在给定状态、时间与条件后只沿一个速度前进。条件平均场通常产生弯曲轨迹；在解唯一的条件下，不同初值的轨迹不能在同一时间相遇后任意分叉。训练配对里的指定终点不是推理输入，也不是每个噪声必须恢复的标签。 因而主案例下一步不是让网络拿到被隐藏的分量编号，而是保留 x、t、c 三类可用输入，用端点速度样本估计这个条件平均。前面的离散两速度算例仅用于手算平方分解，不改变全章的二维数据分布。

04时间、状态与观测条件

速度网络是将当前生成状态、生成时间与已知条件映射为速度向量的参数化函数。三类输入分别提供“在哪里”“处于哪一阶段”“要生成哪类数据”。先定义接口，才能判断拼接、广播与条件编码是否正确。

10耦合决定中间分布与路径难度

端点耦合是同时规定噪声与数据怎样成对出现的联合分布。它不只给出两端各自的分布，还决定中间插值与监督速度。改变耦合可能改变学习难度，但条件直线本身不表示已找到全局最优运输。

12动作块与有效监督

动作块是一次联合生成的多步命令数组，有效监督集合是其中真正有标签的标量坐标。输入可见性与损失有效位控制不同关系。下面分别定义它们，再计算变长或异构动作的分母。

15多峰分布、可逆性与有限时间的边界

多峰分布指同一条件下的密度具有多个峰，不是图像与语言所说的多模态输入。不同噪声沿确定性场可以到达不同区域；流的可逆性则约束这种变换能在有限时间内精确表示什么。下面分别讨论这两件事。

固定条件与初始噪声后，ODE 给出一个确定终点；不同噪声进入场的不同位置，可以被运输到不同高密度区域。速度是局部条件平均，不是对所有最终动作求一个全局平均。因此连续、非线性的流可以产生多峰密度，确定性动力学不等于单点输出。

16定位训练与采样错误

Flow 系统包含路径、回归器、求解器和动作接口，多处错误都可能表现为训练损失或生成结果异常。诊断应先使用可手算端点和解析场，逐步恢复模型与数据随机性。每项对照都要回答一个具体假设，避免同时改变多个因素后无法解释结果。

第一步冻结所有随机性，直接打印一组 noise、action、ttt⁠、xtx_txt​ 和 target，核对端点、有限差分与张量轴。第二步用常量场或解析线性场代替神经网络，独立测试积分器：若方向、步长或第二阶段求值有误，应优先修正采样器。第三步固定少量完整三元组，检查参数确实收到有限梯度并发生更新；这个任务可以过拟合，但不能据此宣称在持续重采样的真实目标上达到零风险。

第四步恢复噪声与时间采样，并按时间区间、动作维度和轨迹长度分别报告误差。只有一个总 Loss 时，容易忽略某些区间严重失真，或者被大量低难度 Padding 掩盖。检查预测速度与目标速度的范数、有效分母、梯度范数和优化器参数集合。条件高维时，可在固定 noise 与 ttt 的情况下替换条件，确认目标网络确实对相关条件敏感，而不是只输出与观测无关的平均动作。

第五步固定网络和初始噪声，逐渐增加积分预算，区分数值误差、模型误差和条件错误；同时记录 NFE 和真实耗时。第六步用同一条样本贯通训练预处理、保存加载、推理后处理，逐维比对单位、归一化、相机顺序和 Action Chunk 对齐。若离线目标正常而部署异常，先完成这条一致性检查，再归因于模型容量或数据不足。每次只改变一个可解释因素，并保留反例与输出证据。

Flow Matching 将生成连接成三个环节：路径提供可监督样本，平方回归估计边际速度，求解器从新噪声积分产生数据。条件速度、理想边际场、学得场与有限步轨迹分别属于不同环节，解释误差时应始终区分。

  • 最小对照：固定数据、噪声、时间、模型权重和采样网格。
  • 必要记录：目标参数化、时间方向、有效分母、NFE、动作反归一化。
  • 验收证据：端点/导数测试、解析 ODE 对照、梯度检查、条件敏感性、训练推理一致性。
