状态表示用数值描述机器人当前可获得的信息，动作表示则定义策略输出的每个数对应哪一种命令或控制参考。位置、位移和速度即使维度相同，也有不同单位、参考系与时间含义。本章先区分目标参考和实测响应，再建立坐标、旋转、归一化与离散化的定义，最后把模型数值按原约定恢复为动作。

01区分命令、参考与实测状态

控制参考是希望控制器追踪的目标，命令是传入控制接口的量，实测状态是系统实际响应的观测。命令可以承载位置或速度参考，却不等于传感器后来测到的值。先定义这些对象，再讨论位移与速度的换算。

位置增量 Δq\Delta qΔq 和速度 q˙\dot qq˙​ 需要通过控制周期关联：在简单零阶保持近似下，Δq≈q˙ Δt\Delta q\approx\dot q\,\Delta tΔq≈q˙​Δt⁠。若把每步位移直接当成速度，或把原来 0.1 秒的数据不变地放到 0.02 秒执行，物理运动尺度会改变。采样频率、命令发送频率与底层伺服频率也应分开记录，插值增加命令次数并不等于增加策略决策频率。

示教记录还可能同时保存命令与实际状态。受碰撞限制时，命令可以继续变化而实测关节几乎不动；跟踪滞后时，两者相差一个动态过程。学习命令重现的是操作者的控制意图，学习实测下一状态则是在拟合已发生结果。选择哪种标签，应由部署控制接口和期望行为决定，不能因文件里哪个字段更方便就替换。

动作接口是一组联合约定

单位与控制周期会改变同一数值的实际效果，控制模式又决定该数值如何被解释。

检查：为每维列出名称、单位、坐标系、发送频率、绝对/相对语义和下游控制模式，并抽样核对命令与实测日志。

02位置增量需要在哪个坐标系表达

坐标系用原点和坐标轴约定一个向量的数值表达。同一物理位移在工具系和基座系可以有不同坐标，转换需要相应旋转。先说明向量在哪个系中定义，再计算相对动作。

设 R 将工具坐标系的向量转换到基座坐标系。已知两时刻末端位置 ptp_tpt​ 与 pt+1p_{t+1}pt+1​ 都以基座系表达，基座系位移是 pt+1−ptp_{t+1}-p_tpt+1​−pt​⁠；工具系位移则是 Rt⊤(pt+1−pt)R_t^\top(p_{t+1}-p_t)Rt⊤​(pt+1​−pt​)⁠。反方向恢复时乘 RtR_tRt​⁠。转置在这里等于旋转矩阵的逆，依赖 R 正交的假设，不能对任意学习出的 3×3 矩阵直接这样做。

换坐标系时，位移向量只受旋转影响，点坐标还涉及平移。把外参的平移项也加到一个增量上，会错误引入固定偏置。主动旋转物体与被动改变坐标表示在公式外观上相似，但含义不同；明确 R 的输入、输出坐标系，再写下向量流向，有助于判断应使用 R 还是 R⊤R^\topR⊤⁠。

当机器人姿态不断变化时，同一个工具系“向前”在基座系中的方向会随之改变。因此训练时用工具系增量、推理时却按基座系执行，会出现某些姿态下正确、在其他姿态下方向错误的故障。使用非单位旋转作为测试输入，能识别被恒等矩阵样例掩盖的坐标错误。

按任务参考选择动作坐标

表示典型场景动作表达的含义
基座系绝对目标目标位置在固定工作空间中定义，控制接口接收绝对位姿直接指向工作空间中的一个目标。
基座系增量需要在固定世界方向上调整，如沿台面方向平移相对于当前参考，沿固定坐标轴移动。
工具系增量接近、插入或沿工具自身方向调整“向前、侧移”等方向随工具姿态一起转动。

例：绕 z 轴旋转 90° 后的位移

  1. 工具系 x 轴在基座系中指向 +y，工具系 y 轴指向 −x。
  2. 若基座位移是 (+0.01,0,0) 米，乘 R⊤R^\topR⊤ 得到工具系位移 (0,−0.01,0) 米。
  3. 再乘 R，应恢复原基座位移；若直接下发 (+0.01,0,0) 为工具系动作，方向会变成基座 +y。

恒等旋转下两个实现可能碰巧相同，非平凡姿态才有辨别力。

03完整相对位姿：顺序不可交换

位姿由位置和朝向共同组成，相对位姿是以前一个位姿为参照描述后一个位姿的变换。参照选在物体自身还是空间固定坐标，会改变乘法顺序。下面先定义两种相对变换，再验证恢复关系。

位姿 T 由旋转 R 和平移 p 组成，可写成 T=[Rp01]T=\begin{bmatrix}R&p\\0&1\end{bmatrix}T=[R0​p1​] 的 4×4 齐次矩阵；SE(3)\mathrm{SE}(3)SE(3) 指由这些三维旋转和平移组成的刚体变换集合。身体坐标下的相对变换定义为 ΔTbody=Tt−1Tt+1\Delta T_{\rm body}=T_t^{-1}T_{t+1}ΔTbody​=Tt−1​Tt+1​⁠，于是 Tt+1=TtΔTbodyT_{t+1}=T_t\Delta T_{\rm body}Tt+1​=Tt​ΔTbody​⁠。空间坐标下的增量可以定义为 ΔTspace=Tt+1Tt−1\Delta T_{\rm space}=T_{t+1}T_t^{-1}ΔTspace​=Tt+1​Tt−1​⁠，对应 Tt+1=ΔTspaceTtT_{t+1}=\Delta T_{\rm space}T_tTt+1​=ΔTspace​Tt​⁠。左右乘不是记号偏好，而是增量表达坐标系的不同。

展开身体增量可见其旋转为 Rt⊤Rt+1R_t^\top R_{t+1}Rt⊤​Rt+1​⁠、平移为 Rt⊤(pt+1−pt)R_t^\top(p_{t+1}-p_t)Rt⊤​(pt+1​−pt​)⁠。因此平移与旋转具有清楚的共同参考。若只把两组欧拉角逐元素相减，然后与工具系位移拼接，通常没有实现上述群上的相对变换；有限旋转不可交换，Euler 角还有周期、轴顺序和奇异性问题。

对于很小的运动，可用局部旋转向量或李代数坐标表示增量，但它是局部参数化，仍需说明指数映射、参考坐标与单位。把局部近似推广到大角度运动前，应通过组合恢复、逆变换和多次更新的对照检查。与机器人接口连接时，尤其要核对库采用的四元数顺序和旋转约定。

04旋转表示与损失要一起设计

旋转表示是用数值参数描述三维朝向的方法，例如角度、旋转矩阵或单位四元数。单位四元数存在两组符号对应同一旋转的情形，因此参数的欧氏距离不总等于物理朝向差。表示约束与损失需要共同定义。

单位四元数以四个数 q=(w,x,y,z)q=(w,x,y,z)q=(w,x,y,z) 表示旋转，并满足 w2+x2+y2+z2=1w^2+x^2+y^2+z^2=1w2+x2+y2+z2=1⁠；分量排列仍需与具体接口一致。同一个旋转可以由 q 与 −q 两个单位四元数表示。直接计算两者欧氏 MSE，会把物理上相同的姿态当成相距很远的标签；若没有单位范数约束，网络输出还可能不对应合法旋转。可以采用一致的表示处理和符号不变的旋转误差，但规范化与符号选择在边界处仍应做数值检查。

Euler 角维度少，但存在周期跳变和参数化奇异性。旋转矩阵有九个数和正交约束；连续六维表示通常还要经过正交化才能得到旋转。不存在只根据输出维数就能决定的最佳表示，关键是数据覆盖、模型优化、解码过程以及评价的几何误差是否匹配。

对 RpredR_{\rm pred}Rpred​ 与 RtrueR_{\rm true}Rtrue​⁠，可用相对旋转的角度衡量姿态差，计算 arccos 前要把理论上在 [−1,1] 的输入按数值误差裁剪。不要把旋转误差的弧度与位置误差的米直接解释成同一种量。训练目标可加权，但评估时应分别报告可解释的物理指标，以免一个标量掩盖某类严重偏差。

05标准化定义了误差的几何

动作标准化是把不同单位的动作映射到模型使用的坐标尺度。标准化后计算等权误差，相当于在物理坐标中采用某种加权度量。下面区分数值尺度、测量噪声与任务容忍度，避免把它当成中性换单位。

以位置（米）、角度（度）与无量纲夹爪命令为例，目标分别为 0.01、90、1，先人为选取参考尺度 0.01、90、1。零预测的未归一化逐维平方误差为 0.0001、8100、1，标准化后均为 1。这只说明所选尺度改变了权重，不说明三个维度的物理重要性相同。若希望保留给定的物理损失权重 wiw_iwi​⁠，应在标准化坐标中使用 wisi2w_i s_i^2wi​si2​⁠。角度的周期、旋转表示和接触约束仍需在动作语义层处理。

例：单位变化与损失尺度

  1. 同一个位置误差为 0.01 米，也等于 10 毫米。
  2. 未标准化 MSE 从 0.0001 变成 100，数值放大 10⁶ 倍，但物理误差没有变化。
  3. 若均值、尺度与标签同时按同一单位转换，标准化后的误差应保持一致。

比较训练损失前先核对单位与尺度；只调任务权重可能是在补偿接口不一致。

令 S=diag⁡(s1,…,sD)S=\operatorname{diag}(s_1,\ldots,s_D)S=diag(s1​,…,sD​)⁠，各 sd>0s_d>0sd​>0⁠，z=S−1(a−μ)z=S^{-1}(a-\mu)z=S−1(a−μ)⁠。预测在物理坐标中的误差 e=a^−ae=\hat a-ae=a^−a⁠，映射到标准化坐标后为 S−1eS^{-1}eS−1e⁠。因此普通平方损失变成 e⊤Mee^\top M ee⊤Me⁠，其中 M=S−⊤S−1M=S^{-\top}S^{-1}M=S−⊤S−1⁠；关于 a^\hat aa^ 的梯度是 2Me2Me2Me⁠。标准化不仅使数值接近，还规定了哪些物理误差在优化中更昂贵。

例如两个动作维的尺度为 0.01 和 0.5，原始误差都是 0.01；标准化平方误差分别为 1 和 0.0004，第一维贡献是第二维的 2500 倍。若尺度来自训练标准差，这表示按数据变化幅度衡量误差，不等于按任务容忍度衡量误差。接触敏感维度即使数据方差大，也可能需要额外任务权重；数据统计量与控制代价不能互相代替。

损失贡献与共享参数梯度还需要区分。设网络输出 qθq_\thetaqθ​⁠，解码为 a^=μ+Sqθ\hat a=\mu+S q_\thetaa^=μ+Sqθ​⁠。原始坐标损失对 q 的梯度为 2Se2Se2Se⁠，标准化损失对 q 的梯度为 2S−1e2S^{-1}e2S−1e⁠；再左乘网络 Jacobian 的转置才是参数梯度。某维误差大不必然主导每个参数，因为该维对应的 Jacobian 可能较小、为零或与其他维贡献抵消。下面保持同一输出 q 和同一物理预测，只更换误差度量，避免将模型结构变化混入对照。

单位换算应该保持这个几何。米变毫米时，动作、均值和尺度都乘 1000，z 与标准化误差不变；只换标签而不换统计量就改变了问题。统计量还要与动作顺序、有效维和训练版本绑定，长度相同不代表每个数都作用于正确坐标。

检查：用固定物理样本验证编码值、反变换结果和单位；检查训练统计来源以及 checkpoint 中保存的数值。

06动作分箱、词表映射与解码误差

动作分箱是把连续范围划成有限区间、用类别索引表示每个动作值的方法；解码再把索引映射回代表值。它建立连续动作与词表之间的接口，同时引入量化误差。先固定边界与中心约定，再分析误差。

离散动作模型需要把连续标签变成类别。一个基础方案是先把各维动作归一化，再将区间 [ℓ,u] 划为 N 个等宽区间，以区间索引 k 作为离散类别，解码时取区间中心。这里明确使用 N+1 个边界、N 个中心；不同实现对“分箱数”和端点的约定可能不同，迁移权重时必须连同原 Tokenizer 一起读取。

分箱索引与模型词表 ID 是两个对象。下面的教学实现使用 i=i0+ki=i_0+ki=i0​+k 将动作类别映射到一个独立 ID 段；实际模型也可能使用反向映射或复用词表末端。训练标签、输出头允许的 ID 和解码器必须严格互逆。若逐维编码动作块，还要固定时间优先或维度优先的展开顺序，并单独处理特殊 Token 与 Padding，不能把它们解码成动作。

对区间内的标量，中心解码的绝对量化误差不超过半个区间宽度。越界值会先被裁剪，发生饱和，此时相对原值的总误差不再受这一上界约束。若物理动作通过 aphys=μ+saa_{\rm phys}=\mu+s aaphys​=μ+sa 恢复，对应的区间内误差上界为 ∣s∣Δ2\frac{|s|\Delta}{2}2∣s∣Δ​⁠；因此分箱数、动作尺度和控制精度需要一起检查。这个上界只描述正确类别的编码误差，并不保证模型预测错类别时仍有同样精度。

逐时刻、逐维分箱通常需要 HDH DHD 个动作 Token。它不等于 FAST：FAST 对动作序列使用离散余弦变换和压缩编码，Token 数量及解码依赖具有不同含义。下面只实现均匀标量分箱，用来检查端点、词表范围与误差界，不模拟某个模型的完整 Tokenizer。

07动作块的参考锚点决定恢复公式

参考锚点是相对动作恢复为目标时所依据的姿态。整块动作可以共享一个观测锚点，也可以逐步相对前一个目标。它们形成不同标签与恢复规则，尤其影响延迟后丢弃前缀的处理。

相对动作序列至少有两种常见含义：每一步都相对当前观测时刻的同一姿态，或每一步相对前一个目标姿态。前者恢复时一直使用同一个锚点，后者需要依次组合；二者不仅训练标签不同，遇到推理延迟和丢弃动作前缀时的处理也不同。必须在数据构造与执行器之间明确约定。

一维例子中，当前位置为 10，未来绝对位置为 11、13、16。固定锚点增量是 1、3、6，逐步增量是 1、2、3。若把前者累加，会得到 11、14、20；若把后者都加到原始位置，只得到 11、12、13。形状相同，结果却系统性错误；仅检查输出范围无法发现这种差异。

如果执行时使用最新实测状态替换原来锚点，要说明这是重新定义参考还是控制补偿。变化的锚点会改变整段计划的几何含义，不一定等价于“更闭环”。对旋转动作，同样的问题通过矩阵连乘体现，更需要保留每段动作的原始参考与时间来源。

08用分层对照验证动作语义

动作接口包含形状、单位、坐标、归一化和时间参考，多项错误还可能在一次往返变换中相互抵消。因此需要让不同层次的测试使用独立的物理参照。验证的目的，是知道某个通过的检查排除了哪些错误，而不是用一个断言代替整个接口审查。

第一层检查形状、有限值、单位和有效位；第二层检查标准化往返；第三层使用已知非平凡位姿验证坐标变换与组合；第四层比较数据管线与部署管线对同一样本的结果。每层解决不同错误，不能因为一个 assert_close 通过就认为整个接口正确。

往返测试本身也有局限：编码与解码如果共享同一个错误单位或错误关节顺序，它们仍可互相抵消。需要额外的具有已知物理含义的样例，例如基座沿一个轴的小位移、某个关节的已知角度变化以及夹爪状态切换。先在受控条件验证命令含义，再将生成模型接入。

旋转矩阵与合成动作可以隔离验证坐标映射和损失。交换动作维、调换 R 与 R⊤R^\topR⊤⁠、只把标签的米改为毫米，会分别破坏维度语义、变换方向与尺度一致性。碰撞、接触与跟踪稳定性没有进入这些计算，需要相应系统模型与实验。

动作向量的意义由对象、单位、坐标系、时间间隔和参考锚点共同定义，归一化或分箱只是在这套意义上再作编码。只有编码与解码沿同一约定对应，模型输出才具有可解释的控制含义。
