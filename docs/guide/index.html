学习路线与运行说明

五个模块，22 节核心课程

课程定位为学院派理论推导、PyTorch 工程实现与面试手撕训练营。建议按以下顺序学习：

  1. 网络基础与视觉表征：Tensor → MLP → CNN。先掌握张量轴、非线性映射和空间感受野。
  2. 现代 Transformer 与多模态骨干：Attention → RoPE → Norm/FFN → Multimodal → Mask → KV Cache。
  3. 生成模型与连续时间建模：VAE → Flow Matching → Diffusion → Score/SDE → DiT。
  4. 具身策略架构与动作建模：BC → Action Chunking / RTC → ACT、Diffusion Policy、Flow Policy → VLA。
  5. 高效微调与后训练对齐：LoRA → Policy Gradient → PPO → DPO / GRPO。

矩阵求导、激活与初始化、PyTorch 自动微分和训练工程放在附录，按需查阅。Robot Agent 是独立专题，继续学习任务级决策、Skill Runtime、World Model 与 Code Policy Evolution。
