# 正文公式修复与手写实现练习更新

## 范围与结论

本次更新针对两项问题：正文公式显示不完整，以及核心课程需要更完整的手写实现练习。保留现有 7 个模块、49 节课程及课程内的“原理 / 代码 / 练习”组织方式。新增练习直接归入 Transformer 和 Flow Matching，不建立另一套题库或速查平台。

## 1. 公式问题与修复

问题不只来自数学渲染器。许多正文把 `J_N`、梯度、下标或线性分式写成普通文本，渲染器从未识别到这些表达式；部分表达式被拆成数个数学片段，使指数、撇号和括号与主体脱离。标题、符号表、示例标题和代码说明也存在漏渲染。同时，静态预渲染与浏览器阅读曾使用不同的解析路径。

本次逐文件审查 12 个课程内容源，完成以下修改：

- 将应当排版的数学表达式写为明确的行内或独立公式，代码标识符保留为代码，避免把两者混为一类。
- 把 LayerNorm Jacobian、条件期望、ELBO 等较长推导调整为独立公式；保留短表达式的行内阅读体验。
- 新增共享的 `dist/math.js`，让静态 HTML 与浏览器使用同一套数学标记解析和 KaTeX 渲染。先保护代码与数学，再处理 Markdown，避免数学括号、星号和链接互相干扰。
- 修复标题、表格单元格、示例、题目与答案说明中的数学显示。数学表达式紧随的中文标点不再单独落到下一行。
- 长独立公式使用自身的横向滚动区域，支持键盘聚焦；修复居中溢出时左侧内容无法查看的问题。公式不会把整页撑宽。
- 搜索摘要从 MathML 提取可读文本，保留分数、上下标、根号和矩阵的关系。例如 `I/r` 不会被压成 `Ir`；仍可用原始 TeX 命令检索。

### 同步纠正的内容

1. MLP 中将“预测对损失的导数”更正为“损失对预测的导数”。
2. Letterbox 坐标变换中的撇号改为真正的上标撇号。
3. Flow Matching 中，向量端点插值协方差的交叉项改为 `t(1-t)(C01 + C01^T)`。原先标量形式的两倍协方差不能直接推广到非对称的向量交叉协方差；新增非对称例子验证。

## 4. 验证边界

- 代码测试是 CPU 上的小型原理与契约验证，不代表真实机器人数据、GPU 混合精度或大规模训练性能。
- 原有 DDP 案例受当前执行环境的进程通信限制，仍明确标为 `environment_blocked`，未将其计为通过；本次未改动该代码。
- 公式解析与扫描可防止已覆盖的格式回归，不能自动证明所有数学内容的正确性。此次修复同时做了源文审查和关键推导的视觉核查。
- 静态正文可直接读取，不等于已经获得搜索引擎收录或排名。
