## 1. 审查发现的主要问题

### 1.1 目录把训练实现、理论前置与应用混在一起

基线为 9 编、46 门课，另有 MLP、CNN、Transformer、Flow Matching 四个并行详细专题。数学和自动微分分散在不同编，生成模型跟在动作表示之后，通用生成理论容易显得只是某种动作模型的附属知识。部分前置关系还把具体实现接口放在概念之前。

重构后用七编建立数学→表示→序列与多模态→生成建模→策略后训练→训练工程→执行评估的主线。正式 prerequisites 已检查为无环，所有前置课程都先于依赖它的课程出现。实现中的跨编联系通过正文和前置链接承担，不另建知识图谱。

### 1.2 四个核心主题存在两套正文和两个学习入口

原基础课与详细专题有大量重合，读者需要判断哪一套是主内容，搜索也会把同一概念分散到两个入口。此次将四篇基础理论与对应专题合并：原课程 ID 成为唯一入口，`content/topics/*.json` 成为相应正文的唯一作者源；基础演示和专题实验的教学条件不同，继续保留在同一篇的代码、练习页。

实际移除了四份各 8 节的旧基础正文，不再以隐藏复制的方式维持两套内容。旧 section、讨论定位、专题路由和练习草稿都有显式映射；没有删除原有 46 个课程 ID。

### 1.3 深度不均，链条断点比章节总量更重要

原 Residual、Normalization、Transformer、Flow Matching 已有值得保留的推导、反例和代码，不能整体替换成概念摘要。本次主要补足完整链条：构造性表示证明、层间 Jacobian、归一化的分母导数、注意力统计假设、多层信息泄漏、VAE 下界、DDPM 后验与变分权重、Score/SDE/ODE 联系，以及生成理论到动作策略的执行接口。

概率基础的 Bayes、总方差与多元高斯，以及微调课程的真实迁移对照原来不够完整，也作了定点补充。评估、采样和分布式基础已有实质内容，审查后保留，没有按建议条目机械新增页面。

### 1.4 部分代码与正文所讲的边界不一致

本次实际修复：

- Behavior Cloning 练习先平方再乘 Mask，无法排除无效标签中的 NaN。改为先选择有效标量，检查有限性，再计算损失；增加解析梯度、空监督和无效值测试。
- 多模态 masked pooling 的 `NaN * 0` 仍会传播 NaN。改为求和前安全替换无效位置，验证不同有效长度及 `1/n_valid` 梯度。
- 标准库混合精度练习的有限输入在反缩放后仍可能溢出。增加反缩放结果与范数的有限性检查，覆盖极大梯度/极小 scale。
- 新端到端实验的第一次 held-out 干预没有进入受测入口，不能证明数据准备隔离。已改为让完整准备函数接收被修改的验证/测试数据，再验证训练统计保持不变。
- 新链接格式化器会把数学中的 `[...](...)` 误识别为无效 Markdown 链接并吞掉乘法因子。修复为保留原表达式，并加入明确的渲染回归检查。

### 1.5 正文依赖 JavaScript，缺少独立可抓取页面

基线主要使用 hash 路由，初始 HTML 缺少完整课程正文。重构后生成每门课的原理、代码、练习真实路径，静态 HTML 已包含正文、代码、参考资料与 KaTeX MathML。JavaScript 用于增强搜索、页面切换和在线练习。此项改善了可读取性，不构成搜索引擎已经收录的证据。

## 4. 内容深化与验证实例

### 4.1 MLP：从表示存在性到可验证构造

保留矩阵反向传播与 Autograd 对照，并加入有限 ReLU 基函数的折线插值构造：以相邻区间斜率差作为折点系数。利用两次 Rolle 定理推导二阶光滑函数在最大网格宽度 h 下的 `M h²/8` 插值误差界。代码验证节点值、非等距区间斜率、参数量以及二次函数的误差。

正文明确区分“存在一组参数”“优化器能找到这组参数”“有限数据上能够泛化”。池化丢失的序列信息不能靠后续 MLP 加深自动恢复；归一化与目标尺度也进入梯度和优化几何的解释。

### 4.2 Residual / Normalization：推导传播算子，给出失败条件

残差课从 `dx_next=(I+J_F)dx` 出发，解释损失反传中的转置，分析多层 Jacobian 的乘积顺序、奇异值界和交叉项。恒等项并不保证梯度稳定；缩放、初始化、Pre/Post Norm 和投影旁路都有各自条件。

新普通/残差对照使用相同深度、宽度、激活、分支初值和读出头，分别测统一 VJP 探针与真实训练。固定配置中，2 层普通网的训练后 MSE 为 0.058482，残差网为 0.081335；24 层未缩放残差的输入 VJP 增益约 10.466。这样的结果被原样保留，用来说明结构与初始化条件，不能归纳为算法胜负。

Norm 从均值、中心化、方差、分母逐步微分，核对输入、gamma、beta 梯度。常量输入归一化输出为零，不表示其 Jacobian 为零；epsilon 会修正尺度不变性。BatchNorm 的训练批次耦合与评估运行统计被明确区分。

### 4.3 CNN：从窗口不等式到采样几何

卷积输出尺寸由合法窗口位置推出；感受野递推不仅给出 r 和 jump，还加入采样中心 a。多层 stride/dilation/padding 的具体例子区分跨度、实际支持集、边界真实像素及反向梯度。

同 shape、同累计 stride、同感受野仍可能存在位置错位，不能据此直接融合。平移等变性附有采样相位、边界和操作条件；不将理论感受野等同于训练后有效感受野。小核堆叠、瓶颈、depthwise/pointwise 与现代块的设计联系在同一篇里解释。

### 4.4 Transformer：统计假设、计算轴与跨层信息流

缩放推导写明独立、零均值条件下 `Var(qᵀk)=tr(ΣqΣk)`，单位协方差才得到 d。进一步解释 Softmax Jacobian、饱和梯度、三条 Q/K/V 反传路径、多头读取矩阵与输出投影。

代码标出 B/T/H/d 轴，手写分头、Mask、Key 轴 Softmax 和输出投影。新增两层网络的布尔可达性、完整输入 Jacobian 与有限差分对照：安全因果结构的未来导数为零，泄漏结构的最大未来导数约 0.02335。前缀第一层投影相同，并不能证明第二层前缀 K/V 仍不变。

KV Cache 以历史表示不随新增内容变化为条件；非方形 Mask、位置偏移与双向去噪/动作生成单独说明，未把缓存直接套到所有 Transformer 推理。

### 4.5 Diffusion / Score / Flow：统一路径，区分目标与采样

DDPM 从两个 Gaussian 核相乘的二次项配方得到后验，再由轨迹 ELBO 推出时间加权的噪声回归。实验核对后验均值的不同表达，以及固定反向方差下 KL 和加权 epsilon MSE 的值、常数差及梯度。DDIM 解释非相邻步、η 与参数化边界。

Score/SDE 推导从状态梯度、分部积分到 Fokker–Planck，再解释概率流 ODE 的 `g²/2` 系数和反向时间符号。Gaussian 路径的 score/noise/velocity 转换同时改变损失权重，端点可能奇异。是否存在指定线性漂移与同一条件加噪核的 SDE，和是否存在共享边际的一般 SDE，是两个不同问题。

FM 从线性端点路径推导条件速度，再用条件期望及平方误差分解说明边缘速度场；连续性方程解释为何该场能推动相同概率路径。Rectified Flow / Reflow 的耦合、Jensen 代价论证、精确场和可积条件均明确，不称为全局 OT 或一步采样保证。

新的二维条件双峰实验实际训练 1,800 次。独立探针目标 MSE 为 2.493094→1.264147，解析边缘场对随机目标的 MSE 仍为 1.217353。64 步 Heun 相对学习场细网格的 RMS 约 0.000396，而学习场与解析场细网格终点差约 0.146887。前者是积分误差，后者包含场估计偏差；继续积分并不自动修复模型。

原始实验 JSON、分布图、训练直线/瞬时速度场/真实 ODE 轨迹、NFE 误差图和绘图脚本均随代码包交付。数值仅对应声明的固定配置，不代表机器人性能。

### 4.6 后训练与工程：从损失几何走到执行

动作标准化明确比较同一输出 q 经 `a_hat=μ+Sq` 解码时，两种损失对 q 的梯度 `2Se` 与 `2S⁻¹e`。位置、角度与夹爪的具体尺度算例展示误差贡献，再通过共享参数 Jacobian 区分输出梯度与参数梯度。训练统计、常量维、异常值、多机器人混合、Min-Max 度量和 Mask 都与该分析连接。

微调新增源→目标的完整受控实验。三个预训练适配路线和未适配基座共享 checkpoint，从零路线共享预训练前随机初始化；固定目标数据与 600 次更新，并分别报告训练误差、目标探针误差和源域保持。实际结果中，未适配基座的目标 MSE 0.001519 小于冻结/LoRA/全量适配的 0.001861/0.003059/0.003689。此结果没有被隐藏，也没有为制造优势而重选 seed。

冻结特征的线性读出还验证精确的二次风险变化：一次实际 Adam 位移的一阶项约 −0.002319，二次项约 +0.031836，源误差实际增加约 0.029517。由此解释冻结或低秩不保证完整系统保持旧行为，以及一阶梯度对齐不保证有限更新降低风险。

训练推理一致性课现在真正贯通：60 个 Episode 按 40/10/10 切分→构造含 NaN padding 的动作窗口→仅由训练集拟合统计→600 次策略更新→持久化模型、统计与配置→新 Python 进程恢复→执行第一步后重新观测的 24 步闭环。实际训练损失 1.130767→0.000430，留出测试动作 MSE 约 2.17e−6，合成闭环最终距离均值约 0.00265。它是可实现线性系统的接口验证，不是 VLA 或真实控制性能实验。

训练异常课继续保留推理式路径：输出/标签/Mask→小子集过拟合→数值范围→梯度存在与尺度→优化器/冻结状态→训练验证差异；每步都有要排除的假设，而非“调整学习率”的经验清单。

## 7. 尚未完成及明确保留的边界

1. **双进程 DDP 主示例**：交付环境限制通信 socket，未运行通过；同课数学与单进程练习已验证。不能将全站状态写成“零受限、全部通过”。
2. **CUDA 与多卡实测**：CPU 数值核验不证明硬件吞吐、GPU AMP 或实际多卡通信行为；代码保留相应配置说明。
3. **真实策略训练与机器人评估**：ACT/Diffusion/Flow 接口课、小型已训练 FM、合成闭环和迁移实验各自有明确用途；没有据此报告真实 VLA 成功率、跨机器人迁移或系统性 OOD 基准。
4. **强化学习工程范围**：必要的优化理论与生成策略 log-prob 边界已覆盖，完整 PPO/SAC 训练系统与长期在线交互不是本期交付内容。
5. **高级生成与控制专题**：一般状态相关扩散矩阵的反向 SDE、复杂流形求解器、高阶自适应 SDE 工具链、完整机器人控制理论没有无差别扩入。
6. **外部实现会演进**：原始论文和官方仓库链接在本次审查时核验；本地教材实验代码随版本交付。上游 main 分支后续变化不能视为教材已经自动同步。
